# Go 语言专家 Skill

Go 语言专家 skill，用于评审和指导 Go 语言相关的技术决策。

## 能力

- 评审 Go 代码组织和结构
- 检查并发模式应用（goroutine, channel, sync 包）
- 验证错误处理最佳实践
- 评估性能优化策略
- 审查泛型使用和类型安全
- 确保遵循 Go 编码规范

## 使用场景

- 评审 Go 项目架构
- 检查并发安全设计
- 评估性能瓶颈和优化方案
- 审查错误处理策略
- 验证 Go 惯用法和代码风格

## 典型评审要点

1. **代码组织**
   - 包名是否规范（小写，无下划线）？
   - 文件结构是否合理？
   - 是否遵循 Go 项目布局？

2. **并发模式**
   - goroutine 生命周期是否正确管理？
   - 是否有 goroutine 泄漏风险？
   - sync 包使用是否正确？
   - 是否考虑了竞态条件？

3. **错误处理**
   - 错误处理是否符合 Go 惯例？
   - 是否使用了 error wrapping？
   - 错误变量是否公开？
   - 是否有忽略错误的地方？

4. **性能考虑**
   - 是否有不必要的内存分配？
   - sync.Pool 使用是否正确？
   - 是否有性能瓶颈？
   - GC 压力是否过大？

5. **类型安全**
   - 泛型使用是否正确？
   - 是否有类型断言滥用？
   - 接口设计是否合理？

## 输出格式

评审输出包含：
- 评分（1-10分）
- 具体问题列表
- 改进建议
- 代码示例（如适用）
- 性能分析（如适用）
