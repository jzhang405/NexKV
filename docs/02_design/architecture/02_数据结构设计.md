### 1.2 WAL 磁盘格式

```go
// WAL 文件格式 (每条记录独立)
//
// +--------------+---------------+------------------+
// | Header (12B) | Entry Data(N) | Checksum (4B)   |
// +--------------+---------------+------------------+
//
// Header 格式 (固定 12 字节):
// +-------------+-------------+-------------+-------------+------------+
// | Type (1B)   | KeyLen (4B) | ValLen (4B) | TsLen (2B)  | Pad (1B)   |
// +-------------+-------------+-------------+-------------+------------+
// Type:   WALType (Put/Delete/Checkpoint)
// KeyLen: Key 数据长度
// ValLen: Value 数据长度
// TsLen:  HLC 时间戳长度 (固定值 10)
// Pad:    未使用，4字节对齐
//
// Entry Data 格式 (变长):
// +-------------+-----------+-----------+
// | Timestamp   | Key       | Value     |
// +-------------+-----------+-----------+
// Timestamp: HLC 序列化数据 (10 字节: 8B pt + 2B c)
// Key:       UTF-8 字符串
// Value:     二进制数据
//
// Checksum: IEEE CRC32 (覆盖 Header + Entry Data)
```

**WAL 条目编码示例**:
```go
// EncodeWALEntry 编码 WAL 条目
func EncodeWALEntry(entry *WALEntry) ([]byte, error) {
    // 1. 序列化 HLC 时间戳 (10 字节)
    timestampData, err := entry.Timestamp.MarshalBinary()
    if err != nil {
        return nil, err
    }

    // 2. 构建 Header (12 字节)
    header := make([]byte, 12)
    header[0] = byte(entry.Type)                          // Type: [0:1]
    binary.BigEndian.PutUint32(header[1:5], uint32(len(entry.Key)))   // KeyLen: [1:5]
    binary.BigEndian.PutUint32(header[5:9], uint32(len(entry.Value))) // ValLen: [5:9]
    binary.BigEndian.PutUint16(header[9:11], uint16(len(timestampData))) // TsLen: [9:11]
    // header[11] 是 Padding，未使用

    // 3. 构建 Entry Data (Timestamp + Key + Value)
    data := make([]byte, 0, 12+len(timestampData)+len(entry.Key)+len(entry.Value))
    data = append(data, header...)         // Header (12B)
    data = append(data, timestampData...)  // Timestamp (10B)
    data = append(data, []byte(entry.Key)...)     // Key (N)
    data = append(data, entry.Value...)          // Value (M)

    // 4. 计算校验和 (覆盖 Header + Entry Data)
    checksum := crc32.ChecksumIEEE(data)

    // 5. 返回完整记录: [Data][Checksum]
    result := append(data, []byte{0, 0, 0, 0}...) // 预分配 4 字节
    binary.BigEndian.PutUint32(result[len(data):], checksum)

    return result, nil
}

// WALEntry WAL 条目结构
type WALEntry struct {
    Type      WALType          // 操作类型
    Key       string           // 键
    Value     []byte           // 值
    Timestamp *clock.HLC       // HLC 时间戳
}
```

### 1.3 快照格式

```go
// Snapshot 快照
type Snapshot struct {
    Version   uint64                 // 快照版本
    Timestamp int64                  // 快照时间
    Data      map[string][]byte      // 数据快照
    Checksum  uint32                 // 校验和
}

// 快照文件格式:
// +--------+--------+--------+--------+--------+
// | Header | Data   | Index  | Checksum      |
// +--------+--------+--------+--------+--------+
//
// Header (64 字节):
// +-------------+--------------+--------------+--------------+
// | Magic (4B)  | Version (8B) | Timestamp(8B)| DataSize(4B) |
// +-------------+--------------+--------------+--------------+
// | IndexSize(4B)| Reserved (36B)             |
// +---------------+--------------------------+
//
// Data: Key-Value 对(MessagePack 编码)
// Index: Key 到 Offset 的映射
```

## 2. 网络数据结构

### 2.1 帧格式

```go
// Frame 帧结构 (16 字节帧头)
type Frame struct {
    Magic     [4]byte       // "NxKV" (4 字节,魔数)
    Type      MessageType   // 消息类型 (2 字节, 100-352)
    CodecType CodecType     // 编解码器类型 (2 字节, 1=MessagePack)
    Length    uint32        // Data 长度 (4 字节)
    CRC32     uint32        // 校验和 (4 字节,IEEE CRC32)
    Data      []byte        // 消息体 (N 字节)
}

// 帧总大小 = 16 + N 字节
```

**帧编码**:
```
+-----------+----------+----------+----------+----------+----------+
| Magic     | Type     |CodecType | Length   | CRC32    | Data     |
| 4 bytes   | 2 bytes  | 2 bytes  | 4 bytes  | 4 bytes  | N bytes  |
+-----------+----------+----------+----------+----------+----------+
  "NxKV"      100-352    1-3        N         N         N
```

**字段说明**:
- **Magic**: `"NxKV"` (4字节ASCII),用于快速协议识别
- **Type**: 消息类型,支持 100-352 范围
- **CodecType**: 编解码器类型 (1=MessagePack, 2=JSON, 3=Protobuf)
- **Length**: Data 字段长度
- **CRC32**: 覆盖 Magic+Type+CodecType+Length+Data 的校验和
- **Data**: 实际消息数据,由 CodecType 指定的编码器序列化

### 2.3 序列化格式

**MessagePack 编码示例**:
```go
// EncodeMessagePack MessagePack 编码
func EncodeMessagePack(v interface{}) ([]byte, error) {
    return msgpack.Marshal(v)
}

// DecodeMessagePack MessagePack 解码
func DecodeMessagePack(data []byte, v interface{}) error {
    return msgpack.Unmarshal(data, v)
}

// 示例: 编码 GossipSyncMessage
```

## 7. 总结

### 7.1 数据结构设计原则

| 原则 | 说明 |
|------|------|
| **紧凑性** | 减少内存和磁盘占用 |
| **对齐** | 64 位对齐,提高访问效率 |
| **版本化** | 支持多版本读取 |
| **可扩展** | 预留扩展字段 |

---

### 7.2 编码格式选择

| 数据类型 | 编码格式 | 理由 |
|---------|---------|------|
| 网络消息 | MessagePack | 高效、无需 IDL |
| 持久化 | 自定义格式 | 紧凑、可控制 |
| 配置文件 | YAML | 人类可读 |
| 日志 | JSON | 结构化、易解析 |
