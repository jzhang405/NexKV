## 1. Go 代码规范

### 1.1 基础规范

#### 遵循官方规范

NexKV 项目严格遵循 Go 语言官方编码规范：

- [Effective Go](https://go.dev/doc/effective_go)
- [Go Code Review Comments](https://github.com/golang/go/wiki/CodeReviewComments)

#### 代码格式化

**自动化格式化**：
```bash
# 使用 gofmt 自动格式化
gofmt -w -s .

# 使用 goimports 管理导入
goimports -w .
```

**CI/CD 检查**：
- 所有提交必须通过 `gofmt` 检查
- 未格式化的代码将被拒绝合并

#### 代码检查

**静态分析**：
```bash
# 使用 go vet 静态检查
go vet ./...

# 使用 golangci-lint 综合检查
golangci-lint run
```

**检查规则**（`.golangci.yml`）：
```yaml
linters:
  enable:
    - govet          # 官方 vet
    - errcheck       # 错误检查
    - staticcheck    # 静态分析
    - unused         # 未使用代码
    - gosimple       # 简化建议
    - structcheck    # 未使用字段
    - varcheck       # 未使用变量
    - ineffassign    # 无效赋值
    - deadcode       # 死代码
    - gofmt          # 格式检查
    - goimports      # 导入排序

linters-settings:
  govet:
    check-shadowing: true
    enable-all: true
```

### 1.2 命名约定

#### 包名

**规范**：
- 简短、小写、单数
- 不使用下划线或混合大小写
- 描述包提供的主要功能

**示例**：

```go
// ✅ 好的包名
package store        // 存储相关
package transport     // 网络传输
package consensus     // 一致性协议
package metadata      // 元数据管理
package rpc           // RPC 通信

// ❌ 不好的包名
package my_store           // 下划线
package transportLayer     // 混合大小写
package stores             // 复数形式
package metadataManagement // 过长
```

**包名与目录名一致**：
```
internal/store/     → package store
internal/transport/ → package transport
pkg/consensus/      → package consensus
```

#### 接口名

**规范**：
- 单方法接口：方法名 + `-er` 后缀
- 多方法接口：描述性名称
- 不使用 `I` 前缀（避免 Java 风格）

**示例**：

```go
// ✅ 单方法接口：动词 + er
type Store interface {
    Put(key string, value []byte) error
    Get(key string) ([]byte, error)
    Delete(key string) error
}

type Transport interface {
    Send(addr string, msg Message) error
    Receive() <-chan Message
    Close() error
}

type Encoder interface {
    Encode(v interface{}) ([]byte, error)
}

type Decoder interface {
    Decode(data []byte, v interface{}) error
}

// ✅ 多方法接口：描述性名称
type MetadataStore interface {
    CreateMetadata(meta *Metadata) error
    UpdateMetadata(meta *Metadata) error
    GetMetadata(id string) (*Metadata, error)
    DeleteMetadata(id string) error
    GetVersion() uint64
}

// ❌ 不好的接口名：I 前缀
type IStore interface {}
type ITransport interface {}
type IMetadataStore interface {}
```

#### 变量名

**规范**：
- 驼峰命名（camelCase 或 PascalCase）
- 简洁明了，避免缩写
- 导出变量使用 PascalCase
- 局部变量使用 camelCase

**示例**：

```go
// ✅ 好的变量名
var nodeCount int
var heartbeatInterval time.Duration
var metadataStore MetadataStore
var gossipProtocol Gossip

// ✅ 简短但清晰的变量名（局部作用域）
func Process(n int) {
    for i := 0; i < n; i++ {  // i 在局部作用域中可接受
        // ...
    }
}

// ❌ 不好的变量名：下划线
var node_count int
var heartbeat_interval time.Duration

// ❌ 不好的变量名：过度缩写
var hbIntv time.Duration
var ms MetadataStore
var nCnt int

// ❌ 不好的变量名：无意义
var data1 interface{}
var temp2 string
```

#### 常量名

**规范**：
- 导出常量使用 PascalCase 或全大写
- 枚举常量使用类型 + iota
- 相关常量分组定义

**示例**：

```go
// ✅ 好的常量名：PascalCase
const MaxRetries = 3
const DefaultTimeout = 30 * time.Second
const MaxPacketSize = 1024 * 1024  // 1MB

// ✅ 枚举常量：类型 + iota
type NodeStatus int

const (
    StatusAlive   NodeStatus = iota  // 0
    StatusSuspect                    // 1
    StatusDead                       // 2
)

type MessageType uint16

const (
    MsgType2PCPrepare MessageType = 100
    MsgType2PCCommit  MessageType = 101
    MsgType2PCRollback MessageType = 102
)

// ✅ 分组定义：相关常量
const (
    // Gossip 配置
    GossipInterval     = 10 * time.Second
    GossipFanout       = 2
    GossipRetries      = 3

    // Quorum 配置
    QuorumTimeout      = 30 * time.Second
    QuorumThreshold    = 0.6  // 60%
)

// ❌ 不好的常量名：无前缀或分组
const (
    alive = 0    // 缺少前缀
    suspect = 1
    dead = 2
)
```

### 1.3 函数规范

#### 函数签名

**规范**：
- 导出函数使用 PascalCase
- 私有函数使用 camelCase
- 参数名清晰明确
- 错误作为最后一个返回值

**示例**：

```go
// ✅ 好的函数签名
func Put(key string, value []byte) error
func Get(key string) ([]byte, error)
func SyncToNode(addr string) error
func CreateShard(meta *ShardMetadata) (*Shard, error)

// ✅ 多返回值：最后一个是 error
func GetData() (data []byte, err error)
func ParseFrame(data []byte) (frame *Frame, err error)
func GetVersion() (version uint64, err error)

// ✅ 接收者命名：简短、一致
func (s *Store) Put(key string, value []byte) error
func (t *TCPTransport) Send(addr string, msg Message) error
func (g *GossipService) SyncToNode(addr string) error

// ❌ 不好的函数签名：参数不明确
func Put(k string, v []byte) error  // k, v 不明确
func Sync(a string) error          // a 不明确
```

#### 错误处理

**规范**：
- 显式处理所有错误
- 禁止忽略错误
- 添加上下文信息
- 使用 `%w` 包装错误

**示例**：

```go
// ✅ 好的错误处理：显式处理、添加上下文
func SaveMetadata(meta *Metadata) error {
    // 1. 验证输入
    if err := validate(meta); err != nil {
        return fmt.Errorf("validation failed for metadata %s: %w", meta.ID, err)
    }

    // 2. 保存数据
    if err := s.store.Put(meta.ID, meta); err != nil {
        return fmt.Errorf("failed to save metadata %s: %w", meta.ID, err)
    }

    // 3. 更新版本
    if err := s.version.Increment(); err != nil {
        return fmt.Errorf("failed to increment version: %w", err)
    }

    return nil
}

// ✅ 错误链：使用 errors.Is/As
func ConnectNode(addr string) error {
    err := transport.Dial(addr)
    if err != nil {
        if errors.Is(err, os.ErrNotExist) {
            return fmt.Errorf("node config not found: %s", addr)
        }
        var netErr *net.OpError
        if errors.As(err, &netErr) {
            return fmt.Errorf("network error: %s", netErr.Op)
        }
        return fmt.Errorf("failed to connect: %w", err)
    }
    return nil
}

// ❌ 不好的错误处理：忽略错误
func SaveMetadata(meta *Metadata) error {
    validate(meta)               // 忽略错误
    s.store.Put(meta.ID, meta)   // 忽略错误
    return nil
}

// ❌ 不好的错误处理：吞掉错误
func ProcessData(data []byte) error {
    result, _ := process(data)  // 忽略错误
    return nil
}
```

#### 错误定义

**规范**：
- 包级变量定义标准错误
- 使用 `Err` 前缀
- 实现 `Error()` 方法的自定义错误
- 提供 `Is()` 和 `As()` 支持

**示例**：

```go
// ✅ 好的错误定义：包级变量、Err 前缀
var (
    ErrKeyNotFound    = errors.New("key not found")
    ErrInvalidFormat  = errors.New("invalid format")
    ErrTimeout        = errors.New("operation timeout")
    ErrVersionConflict = errors.New("version conflict")
    ErrNodeNotReady   = errors.New("node not ready")
)

// ✅ 自定义错误：实现 Error() 方法
type ValidationError struct {
    Field   string
    Message string
    Cause   error
}

func (e *ValidationError) Error() string {
    return fmt.Sprintf("validation failed on field %s: %s", e.Field, e.Message)
}

func (e *ValidationError) Unwrap() error {
    return e.Cause
}

// ✅ 错误类型：支持 errors.Is/As
type NotFoundError struct {
    Resource string
    ID       string
}

func (e *NotFoundError) Error() string {
    return fmt.Sprintf("%s %s not found", e.Resource, e.ID)
}

func (e *NotFoundError) Is(target error) bool {
    _, ok := target.(*NotFoundError)
    return ok
}
```

### 1.4 结构体规范

#### 字段排序

**规范**：
- 导出字段在前，未导出字段在后
- 同类型字段按字母序排序
- 结构体标签使用 `json` 和 `yaml`

**示例**：

```go
// ✅ 好的结构体：字段排序合理、有标签
type Node struct {
    // 导出字段（按字母序）
    ID        string       `json:"id" yaml:"id"`
    Addr      string       `json:"addr" yaml:"addr"`
    Status    NodeStatus   `json:"status" yaml:"status"`
    CreatedAt time.Time    `json:"created_at" yaml:"created_at"`
    UpdatedAt time.Time    `json:"updated_at" yaml:"updated_at"`

    // 未导出字段（按字母序）
    mu       sync.RWMutex
    cache    *lru.Cache
    stopCh   chan struct{}
}

// ✅ 嵌套字段：有标签避免歧义
type Shard struct {
    ID     string  `json:"id"`
    Status Status  `json:"status"`
    Nodes  []Node  `json:"nodes"`
}

// ✅ 配置结构体：使用 omitempty
type Config struct {
    ClusterName string        `json:"cluster_name" yaml:"cluster_name"`
    NodeID      string        `json:"node_id" yaml:"node_id"`
    Addr        string        `json:"addr" yaml:"addr"`

    // Gossip 配置
    GossipInterval time.Duration `json:"gossip_interval,omitempty" yaml:"gossip_interval,omitempty"`
    GossipFanout   int          `json:"gossip_fanout,omitempty" yaml:"gossip_fanout,omitempty"`

    // Quorum 配置
    QuorumTimeout  time.Duration `json:"quorum_timeout,omitempty" yaml:"quorum_timeout,omitempty"`
    QuorumThreshold float64      `json:"quorum_threshold,omitempty" yaml:"quorum_threshold,omitempty"`
}
```

#### 构造函数

**规范**：
- 使用 `New` 前缀
- 返回接口类型而非具体类型
- 提供配置选项模式

**示例**：

```go
// ✅ 好的构造函数
func NewMemoryStore() *MemoryStore {
    return &MemoryStore{
        data:    make(map[string][]byte),
        version: atomic.Uint64{},
    }
}

// ✅ 配置选项模式
type StoreOption func(*Store)

func WithCacheSize(size int) StoreOption {

func WithWAL(wal WAL) StoreOption {

func NewStore(opts ...StoreOption) *Store {
    s := &Store{

    }

// 使用示例
store := NewStore(
```

### 1.5 并发规范

#### 使用 Channel 通信

**规范**：
- 优先使用 channel 传递数据
- 避免共享内存
- 使用 select 处理多 channel

**示例**：

```go
// ✅ 好的并发：使用 channel 传递数据
func worker(id int, tasks <-chan Task, results chan<- Result) {
    for task := range tasks {
        result := process(task)
        results <- Result{WorkerID: id, Value: result}
    }
}

func StartWorkers(numWorkers int) {
    tasks := make(chan Task, 100)
    results := make(chan Result, 100)

    // 启动 workers
    for i := 0; i < numWorkers; i++ {
        go worker(i, tasks, results)
    }

    // 分发任务
    go func() {
        for _, task := range getAllTasks() {
            tasks <- task
        }
        close(tasks)
    }()

    // 收集结果
    for i := 0; i < numWorkers; i++ {
        result := <-results
        handleResult(result)
    }
}

// ✅ 使用 select 处理多 channel
func service(stopCh <-chan struct{}, reqCh <-chan Request) {
    for {
        select {
        case req := <-reqCh:
            handleRequest(req)
        case <-stopCh:
            cleanup()
            return
        }
    }
}
```

#### 互斥锁使用

**规范**：
- 使用 defer 释放锁
- 读写分离（RWMutex）
- 避免锁嵌套

**示例**：

```go
// ✅ 好的锁使用：defer 释放
func (s *Store) Get(key string) ([]byte, error) {
    s.mu.RLock()
    defer s.mu.RUnlock()

    return s.data[key], nil
}

func (s *Store) Put(key string, value []byte) error {
    s.mu.Lock()
    defer s.mu.Unlock()

    s.data[key] = value
    return nil
}

// ✅ 读写锁：读写分离
type SafeStore struct {
    mu   sync.RWMutex
    data map[string][]byte
}

func (s *SafeStore) Get(key string) ([]byte, error) {
    s.mu.RLock()
    defer s.mu.RUnlock()
    return s.data[key], nil
}

func (s *SafeStore) Put(key string, value []byte) error {
    s.mu.Lock()
    defer s.mu.Unlock()
    s.data[key] = value
    return nil
}

// ❌ 不好的并发：共享状态 + goroutine
var count int

func increment() {
    go func() {
        count++  // 数据竞争
    }()
}

// ✅ 修复：使用 sync/atomic
var count atomic.Int64

func increment() {
    count.Add(1)
}
```

#### 避免死锁

**规范**：
- 按固定顺序获取锁
- 使用 context 控制超时
- 避免锁嵌套

**示例**：

```go
// ✅ 好的锁顺序：固定顺序
func (s *Service) Transfer(from, to string, amount int) error {
    // 始终按 ID 字典序获取锁
    if from > to {
        from, to = to, from
    }

    s.mu.Lock(from)
    defer s.mu.Unlock(from)

    s.mu.Lock(to)
    defer s.mu.Unlock(to)

    // 执行转账
    return s.doTransfer(from, to, amount)
}

// ✅ 使用 context 控制超时
func (s *Service) DoWork(ctx context.Context) error {
    done := make(chan error, 1)

    go func() {
        done <- s.doSlowWork()
    }()

    select {
    case err := <-done:
        return err
    case <-ctx.Done():
        return ctx.Err()  // 超时或取消
    }
}
```

### 1.6 资源管理

#### 使用 defer 确保释放

**规范**：
- 使用 defer 确保资源释放
- defer 语句紧跟资源获取
- 优先使用 RAII 模式

**示例**：

```go
// ✅ 好的资源管理：使用 defer 确保释放
func ProcessFile(path string) error {
    f, err := os.Open(path)
    if err != nil {
        return fmt.Errorf("failed to open file: %w", err)
    }
    defer f.Close()

    // 处理文件
    data, err := io.ReadAll(f)
    if err != nil {
        return fmt.Errorf("failed to read file: %w", err)
    }

    return processData(data)
}

// ✅ 数据库连接
func QueryData(db *sql.DB) error {
    ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
    defer cancel()

    tx, err := db.BeginTx(ctx, nil)
    if err != nil {
        return fmt.Errorf("failed to begin transaction: %w", err)
    }
    defer tx.Rollback()  // 如果 Commit 成功，Rollback 是空操作

    // 执行查询
    rows, err := tx.QueryContext(ctx, "SELECT * FROM users")
    if err != nil {
        return err
    }
    defer rows.Close()

    // 处理结果
    return processRows(rows)
}

// ✅ 网络连接
func ConnectTo(addr string) error {
    conn, err := net.Dial("tcp", addr)
    if err != nil {
        return fmt.Errorf("failed to connect: %w", err)
    }
    defer conn.Close()

    // 使用连接
    return communicate(conn)
}
```

#### 实现 io.Closer 接口

**规范**：
- 资源类型实现 `Close()` 方法
- `Close()` 方法保证幂等性
- 支持多次调用

**示例**：

```go
// ✅ 实现 io.Closer 接口
type Store struct {
    data    map[string][]byte
    file    *os.File
    closed  bool
    mu      sync.Mutex
}

func (s *Store) Close() error {
    s.mu.Lock()
    defer s.mu.Unlock()

    if s.closed {
        return nil  // 幂等性
    }

    // 刷盘
    if err := s.flush(); err != nil {
        return err
    }

    // 关闭文件
    if s.file != nil {

        }
    }
```

## 3. 错误处理规范

### 3.1 错误包装

**规范**：
- 使用 `fmt.Errorf` 添加上下文
- 使用 `%w` 包装错误（支持 errors.Is/As）
- 错误链不超过 3 层

**示例**：

```go
// ✅ 好的错误包装：添加上下文信息
func (s *Service) SaveUser(id string, user *User) error {
    // 验证用户
    if err := validate(user); err != nil {
        return fmt.Errorf("validation failed for user %s: %w", id, err)
    }

    // 保存到存储
    if err := s.store.Put(id, user); err != nil {
        return fmt.Errorf("failed to save user %s: %w", id, err)
    }

    // 更新索引
    if err := s.index.Add(id, user.Email); err != nil {
        return fmt.Errorf("failed to index user %s: %w", id, err)
    }

    return nil
}

// ✅ 错误链：使用 errors.Is/As
func HandleError(err error) {
    // 检查特定错误
    if errors.Is(err, ErrNotFound) {
        log.Info("resource not found")
        return
    }

    // 提取特定错误类型
    var netErr *net.OpError
    if errors.As(err, &netErr) {
        log.Printf("network error: %s", netErr.Op)
        return
    }

    // 其他错误
    log.Printf("unexpected error: %v", err)
}

// ❌ 不好的错误包装：丢失原始错误
func SaveUser(user *User) error {
    if err := validate(user); err != nil {
        return errors.New("validation failed")  // 丢失原始错误
    }
    // ...
}
```

## 5. 性能规范

### 5.1 避免不必要的分配

**规范**：
- 复用缓冲区
- 预分配容量
- 避免循环内分配

**示例**：

```go
// ❌ 不好的代码：每次循环都分配
func ProcessItems(items []Item) error {
    for _, item := range items {
        data := make([]byte, 1024)  // 每次循环分配
        process(item, data)
    }
}

// ✅ 好的代码：复用缓冲区
func ProcessItems(items []Item) error {
    data := make([]byte, 1024)
    for _, item := range items {
        process(item, data)
    }
}

// ✅ 预分配容量
func BuildResult(keys []string) []Result {
    results := make([]Result, 0, len(keys))
    for _, key := range keys {
        results = append(results, fetchResult(key))
    }
    return results
}
```

---

### 5.2 使用 sync.Pool

**规范**：
- 对象分配频繁时使用 sync.Pool
- 重置对象后再放回 Pool
- 注意并发安全

**示例**：

```go
// ✅ 好的代码：使用 sync.Pool 复用对象
var framePool = sync.Pool{
    New: func() interface{} {
        return &Frame{
            Data: make([]byte, 0, 1024),
        }
    },
}

func getFrame() *Frame {
    return framePool.Get().(*Frame)
}

func putFrame(frame *Frame) {
    frame.Reset()
    framePool.Put(frame)
}

func ProcessData(data []byte) error {
    frame := getFrame()
    defer putFrame(frame)

    frame.Data = append(frame.Data, data...)
    return sendFrame(frame)
}
```

---

### 5.3 避免锁竞争

**规范**：
- 减小锁粒度
- 使用读写锁
- 使用无锁数据结构

**示例**：

```go
// ❌ 不好的代码：粗粒度锁
func (s *Store) Process(items []Item) {
    s.mu.Lock()
    defer s.mu.Unlock()

    for _, item := range items {
        s.processItem(item)  // 持锁时间过长
    }
}

// ✅ 好的代码：细粒度锁
func (s *Store) Process(items []Item) {
    for _, item := range items {
        s.mu.Lock()
        s.processItem(item)
        s.mu.Unlock()
    }
}

// ✅ 使用 sync.Map 替代 map + mutex
type Cache struct {
    data sync.Map
}

func (c *Cache) Get(key string) ([]byte, bool) {
    value, ok := c.data.Load(key)
    if !ok {
        return nil, false
    }
    return value.([]byte), true
}
```

## 6. 安全规范

### 6.1 输入验证

**规范**：
- 验证所有外部输入
- 限制资源使用
- 防止注入攻击

**示例**：

```go
// ✅ 好的代码：验证输入
func Put(key string, value []byte) error {
    // 验证键
    if key == "" {
        return ErrEmptyKey
    }
    if len(key) > MaxKeySize {
        return fmt.Errorf("key too large: %d > %d", len(key), MaxKeySize)
    }

    // 验证值
    if len(value) > MaxValueSize {
        return fmt.Errorf("value too large: %d > %d", len(value), MaxValueSize)
    }

    // 验证键格式（防止路径遍历）
    if strings.Contains(key, "..") {
        return fmt.Errorf("invalid key: contains path traversal")
    }

    // 处理逻辑
    return nil
}

const (
    MaxKeySize   = 256   // 256 字节
    MaxValueSize = 1<<20 // 1MB
)
```

### 6.2 避免敏感信息泄露

**规范**：

- 不在错误中泄露敏感信息
