## 1. Phase 1: 基础设施层

### 1.1 混合逻辑时钟（HLC）

**核心实现**：`internal/metadata/clock/hlc.go`

```go
type HLC struct {
    mu       sync.Mutex
    nodeID   uint16      // 节点标识
    wallTime int64       // 物理时钟时间戳（毫秒）
    logical  int32       // 逻辑时钟计数器
}

type Timestamp uint64
```

**运行时特性**：

| 特性 | 说明 | 运行时行为 |
|------|------|-----------|
| **单调递增** | 即使物理时钟回退，HLC 仍保证单调性 | 逻辑时钟递增补偿 |
| **精度控制** | 16 位逻辑时钟支持每毫秒 65536 个事件 | 高吞吐场景 |
| **节点隔离** | 每个节点独立维护 HLC，通过 NTP 同步 | 分布式独立运行 |

**时钟回退处理**：

```go
func (h *HLC) Now() Timestamp {
    now := time.Now().UnixMilli()

    if now < h.wallTime {
        // 物理时钟回退，仅使用逻辑时钟
        return (Timestamp(h.wallTime) << 16) | Timestamp(h.logical)
    }

    return h.Update(now)
}
```

**性能指标**：

| 指标 | 值 |
|------|-----|
| 单次操作延迟 | < 100ns |
| 吞吐量 | > 10M ops/s |
| 内存占用 | 24 字节 |

### 2.1 MVStore 多版本存储引擎

**核心实现**：`internal/metadata/store/mvstore.go`

```go
type MVStore struct {
    mu            sync.RWMutex
    memTable      *MemTable         // 内存表
    wal           *WAL               // 预写日志
    flushCh       chan struct{}       // 刷盘信号
    flushInterval time.Duration      // 刷盘间隔
}

type MemTable struct {
    mu    sync.RWMutex
    data  map[string]*MVRecord  // key -> 多版本记录
}

type MVRecord struct {
    Key        string
    Versions   []*Version  // 版本链
    MinVersion uint64      // 最小活跃版本
}

type Version struct {
    Value     []byte
    Timestamp uint64
    TxnID     uint64
    Deleted   bool
}
```

**运行时行为**：

#### Put 操作

1. **WAL 预写**：先写日志，保证持久性
2. **内存更新**：更新 MemTable，添加新版本
3. **异步刷盘**：后台定期刷盘到 SSTable

```go
func (m *MVStore) Put(key string, value []byte) error {
    // 1. 写入 WAL
    entry := &WALLogEntry{
        Timestamp:  time.Now(),
        Operation:  WALEntry,
        Key:        key,
        Value:      value,
        TxnID:      txnID,
    }
    if err := m.wal.Append(entry); err != nil {
        return err
    }

    // 2. 更新内存表
    version := &Version{
        Value:     value,
        Timestamp: uint64(time.Now().UnixNano()),
        TxnID:     txnID,
        Deleted:   false,
    }
    record.Versions = append(record.Versions, version)

    // 3. 触发异步刷盘
    select {
    case m.flushCh <- struct{}{}:
    default:
    }

    return nil
}
```

#### Get 操作（MVCC）

```go
func (m *MVStore) Get(key string, version uint64) ([]byte, error) {
    record, exists := m.memTable.data[key]
    if !exists {
        return nil, ErrKeyNotFound
    }

    // 读取最新版本
    if version == 0 {
        latest := record.Versions[len(record.Versions)-1]
        if latest.Deleted {
            return nil, ErrKeyNotFound
        }
        return latest.Value, nil
    }

    // 读取指定版本
    for i := len(record.Versions) - 1; i >= 0; i-- {
        v := record.Versions[i]
        if v.Timestamp <= version && !v.Deleted {
            return v.Value, nil
        }
    }

    return nil, ErrVersionNotFound
}
```

**MVCC 特性**：
- **快照隔离**：读取指定时间点的数据
- **无锁读取**：读操作不阻塞写操作
- **版本可见性**：自动选择正确的数据版本

#### Delete 操作（软删除）

```go
func (m *MVStore) Delete(key string) error {
    // 标记删除，添加删除标记
    version := &Version{
        Timestamp: uint64(time.Now().UnixNano()),
        TxnID:     txnID,
        Deleted:   true,
    }
    record.Versions = append(record.Versions, version)
    return nil
}
```

**性能指标**：

| 指标 | 值 |
|------|-----|
| Put 延迟 | < 1μs (内存) |
| Get 延迟 | < 500ns (内存) |
| 吞吐量 | > 1M ops/s (单线程) |
| 并发扩展 | 线性扩展 |

```go
}

    Key        string
    Value      []byte
    OldValue   []byte
    TxnID      uint64
}
```

**运行时行为**：

#### WAL 追加写入

```go
func (w *WAL) Append(entry *WALLogEntry) error {
    w.mu.Lock()
    defer w.mu.Unlock()

    // 序列号递增
    entry.Sequence = w.sequence
    w.sequence++

    // 检查文件大小，触发轮换
    if w.size >= w.maxSize {
        if err := w.rotate(); err != nil {
            return err
        }
    }

    // 写入日志
    w.encoder.Encode(entry)

    // 强制刷盘
    w.file.Sync()

    w.size += int64(binary.Size(entry))
    return nil
}
```

**WAL 特性**：
- **顺序写入**：保证日志连续性
- **强制刷盘**：Sync() 确保持久化
- **自动轮换**：达到大小限制自动切换文件

#### WAL 恢复

```go
func (w *WAL) Recover() (map[string]*WALLogEntry, error) {
    // 重新打开文件
    file, err := os.Open(w.path)
    if err != nil {
        return nil, err
    }
    defer file.Close()

    decoder := gob.NewDecoder(file)
    entries := make(map[string]*WALLogEntry)

    // 读取所有日志条目
    for {
        var entry WALLogEntry
        err := decoder.Decode(&entry)
        if err == io.EOF {
            break
        }

        // 只保留最后一次操作
        entries[entry.Key] = &entry
    }

    return entries, nil
}
```

**恢复策略**：
- **重放日志**：从最新 WAL 重放所有操作
- **幂等性**：支持重复恢复
- **断点续传**：支持从任意位置恢复

**性能指标**：

| 指标 | 值 |
|------|-----|
| Append 延迟 | < 100μs (含 Sync) |
| 恢复速度 | > 10K entries/s |
| 文件大小 | 支持 > 1GB |

## 3. Phase 3: 传输层

### 3.1 自定义帧格式

**核心实现**：`internal/metadata/transport/frame.go`

```go
type Frame struct {
    Magic     [4]byte  // "NxKV" 魔数（4 字节）
    Type      uint16   // 消息类型（2 字节）
    CodecType uint16   // 编码类型（2 字节）
    Length    uint32   // 数据长度（4 字节）
    CRC32     uint32   // CRC32 校验和（4 字节）
    Data      []byte   // 消息数据（变长）
}

// 帧头固定大小：16 字节
const FrameHeaderSize = 16
```

**帧格式示意图**：

```
|<- 4 ->|<- 2 ->|<- 2 ->|<- 4 ->|<- 4 ->|<- 变长 ->|
+--------+--------+--------+--------+--------+----------+
| Magic  | Type   | Codec  | Length | CRC32  | Data     |
+--------+--------+--------+--------+--------+----------+
  "NxKV"  消息类型  编码器   数据长度  校验和   消息体
```

**运行时行为**：

#### 帧序列化

```go
func (f *Frame) Serialize() ([]byte, error) {
    // 1. 验证魔数
    if string(f.Magic[:]) != FrameMagic {
        return nil, ErrInvalidMagic
    }

    // 2. 计算 CRC32
    if len(f.Data) > 0 {
        f.CRC32 = crc32.ChecksumIEEE(f.Data)
    }

    // 3. 创建缓冲区（帧头 16 字节 + 数据）
    buf := make([]byte, FrameHeaderSize+len(f.Data))

    // 4. 写入帧头（大端序）
    copy(buf[0:4], f.Magic[:])
    binary.BigEndian.PutUint16(buf[4:6], f.Type)
    binary.BigEndian.PutUint16(buf[6:8], f.CodecType)
    binary.BigEndian.PutUint32(buf[8:12], f.Length)
    binary.BigEndian.PutUint32(buf[12:16], f.CRC32)

    // 5. 写入数据
    copy(buf[16:], f.Data)

    return buf, nil
}
```

#### 帧反序列化

```go
func DeserializeFrame(data []byte) (*Frame, error) {
    // 1. 检查最小长度
    if len(data) < FrameHeaderSize {
        return nil, ErrFrameTooShort
    }

    frame := &Frame{}

    // 2. 读取帧头
    copy(frame.Magic[:], data[0:4])
    frame.Type = binary.BigEndian.Uint16(data[4:6])
    frame.CodecType = binary.BigEndian.Uint16(data[6:8])
    frame.Length = binary.BigEndian.Uint32(data[8:12])
    frame.CRC32 = binary.BigEndian.Uint32(data[12:16])

    // 3. 验证魔数
    if string(frame.Magic[:]) != FrameMagic {
        return nil, ErrInvalidMagic
    }

    // 4. 验证长度
    if uint32(len(data)-FrameHeaderSize) != frame.Length {
        return nil, ErrLengthMismatch
    }

    // 5. 读取数据
    if frame.Length > 0 {
        frame.Data = make([]byte, frame.Length)
        copy(frame.Data, data[16:])

        // 6. 验证 CRC32
        if crc32.ChecksumIEEE(frame.Data) != frame.CRC32 {
            return nil, ErrCRCMismatch
        }
    }

    return frame, nil
}
```

**性能指标**：

| 操作 | 延迟 | 吞吐量 |
|------|------|--------|
| 创建帧 | < 100ns | > 10M ops/s |
| 序列化 | < 500ns | > 2M ops/s |
| 反序列化 | < 600ns | > 1.6M ops/s |
| CRC32 计算 | < 200ns | > 5M ops/s |

### 3.3 TCP 传输实现

**核心实现**：`internal/metadata/transport/tcp_transport.go`

**运行时行为**：

#### 连接池管理

```go
func (t *TCPTransport) getOrCreateConnection(addr string) (net.Conn, error) {
    // 1. 尝试从连接池获取（读锁）
    t.connectionsMu.RLock()
    conn, exists := t.connections[addr]
    t.connectionsMu.RUnlock()

    if exists && conn != nil {
        return conn, nil
    }

    // 2. 创建新连接（写锁）
    t.connectionsMu.Lock()
    defer t.connectionsMu.Unlock()

    // 3. 双重检查
    if conn, exists := t.connections[addr]; exists && conn != nil {
        return conn, nil
    }

    // 4. 建立新连接
    conn, err := net.DialTimeout("tcp", addr, 5*time.Second)
    if err != nil {
        return nil, err
    }

    // 5. 设置心跳
    if tcpConn, ok := conn.(*net.TCPConn); ok {
        tcpConn.SetKeepAlive(true)
        tcpConn.SetKeepAlivePeriod(t.config.KeepAliveInterval)
    }

    // 6. 存入连接池
    t.connections[addr] = conn
    t.stats.Connections.Add(1)

    return conn, nil
}
```

**连接池特性**：
- 自动复用：优先使用已有连接
- 双重检查：避免重复创建
- 心跳保活：TCP Keep-Alive 机制
- 线程安全：读写锁保护

#### 发送消息

```go
func (t *TCPTransport) Send(ctx context.Context, addr string, msg Message) error {
    // 1. 获取或创建连接
    conn, err := t.getOrCreateConnection(addr)
    if err != nil {
        return err
    }

    // 2. 编码消息
    codec := &MessagePackCodec{}
    data, err := codec.Encode(msg)
    if err != nil {
        return err
    }

    // 3. 封装帧
    frame := &Frame{
        Magic:     [4]byte{'N', 'x', 'K', 'V'},
        Type:      uint16(msg.Type()),
        CodecType: uint16(CodecTypeMessagePack),
        Length:    uint32(len(data)),
        Data:      data,
    }

    // 4. 序列化帧
    frameData, err := frame.Serialize()
    if err != nil {
        return err
    }

    // 5. 发送数据
    if deadline, ok := ctx.Deadline(); ok {
        conn.SetWriteDeadline(deadline)
    }
    _, err = conn.Write(frameData)

    // 6. 更新统计
    t.stats.MessagesSent.Add(1)
    t.stats.BytesSent.Add(int64(len(frameData)))

    return err
}
```

#### 接收消息

```go
func (t *TCPTransport) handleConnection(conn net.Conn) {
    defer conn.Close()

    // 设置超时
    conn.SetReadDeadline(time.Now().Add(t.config.ReadTimeout))

    for {
        // 1. 读取帧头
        header := make([]byte, FrameHeaderSize)
        _, err := io.ReadFull(conn, header)
        if err != nil {
            return
        }

        // 2. 解析帧头
        frame, err := DeserializeFrame(header)
        if err != nil {
            return
        }

        // 3. 读取数据
        if frame.Length > 0 {
            frame.Data = make([]byte, frame.Length)
            _, err = io.ReadFull(conn, frame.Data)
            if err != nil {
                return
            }
        }

        // 4. 解码消息
        codec := &MessagePackCodec{}
        msg, err := codec.Decode(frame.Data)
        if err != nil {
            return
        }

        // 5. 发送到接收通道
        select {
        case t.recvCh <- msg:
            t.stats.MessagesReceived.Add(1)
        case <-t.doneCh:
            return
        }
    }
}
```

**传输层性能**：

| 传输类型 | 延迟 | 吞吐量 | 连接数 |
|---------|------|--------|--------|
| TCP (localhost) | < 100μs | > 100K msg/s | 1000+ |
| Memory | < 1μs | > 1M msg/s | 无限制 |

```go
func (m *MemoryTransport) Send(ctx context.Context, nodeID string, msg Message) error {
```

```go
func (g *GossipService) selectRandomPeers(count int) []string {
    g.nodeListMu.RLock()
    defer g.nodeListMu.RUnlock()

    if len(g.nodeList) <= count {
        return g.nodeList
    }

    // Fisher-Yates 洗牌算法
    shuffled := make([]string, len(g.nodeList))
    copy(shuffled, g.nodeList)

    rand.Shuffle(len(shuffled), func(i, j int) {
        shuffled[i], shuffled[j] = shuffled[j], shuffled[i]
    })

    return shuffled[:count]
}
```

```go
func (g *GossipService) syncToNode(addr string) error {
    // 1. 获取本地版本
    localVersion := g.metadataStore.GetVersion()

    // 2. 请求远程版本
    req := &GossipDigestMessage{
        NodeID:  g.localNodeID,
        Version: localVersion,
    }

    var rep *GossipDigestReplyMessage
    err := g.transport.SendAndReceive(context.Background(), addr, req, &rep)
    if err != nil {
        g.stats.SyncsFailed.Add(1)
        return err
    }

    // 3. 远程版本更高，请求变更日志
    if rep.Version > localVersion {
        syncReq := &GossipSyncMessage{
            NodeID:  g.localNodeID,
            Version: localVersion,
        }

        var syncRep *GossipSyncReplyMessage
        err := g.transport.SendAndReceive(context.Background(), addr, syncReq, &syncRep)
        if err != nil {
            g.stats.SyncsFailed.Add(1)
            return err
        }

        // 应用变更日志
        for _, changeLog := range syncRep.ChangeLogs {
            g.metadataStore.applyChangeLog(changeLog)
            g.stats.ChangesSynced.Add(1)
        }
    }

    // 4. 本地版本更高，发送变更日志
    if localVersion > rep.Version {
        changeLogs := g.metadataStore.GetChangeLogs(rep.Version)

        syncRep := &GossipSyncReplyMessage{
            NodeID:     g.localNodeID,
            ChangeLogs: changeLogs,
        }

        err := g.transport.Send(context.Background(), addr, syncRep)
        if err != nil {
            g.stats.SyncsFailed.Add(1)
            return err
        }

        g.stats.ChangesSynced.Add(int64(len(changeLogs)))
    }

    g.stats.SyncsSuccess.Add(1)
    return nil
}
```

- **增量同步**：只传输变更部分

- **随机选点**：Fisher-Yates 算法保证公平性

```go
func (q *QuorumService) Propose(ctx context.Context, changeLog *MetadataChangeLog) error {
    // 1. 生成提案 ID
    proposalID := fmt.Sprintf("%s-%d", q.localNodeID, q.proposalID.Add(1))

    // 2. 创建提案
    proposal := &QuorumProposal{
        ID:        proposalID,
        Proposer:   q.localNodeID,
        ChangeLog:  changeLog,
        Votes:     make(map[string]bool),
        StartTime: time.Now(),
        Status:    QuorumStatusPending,
    }

    // 3. 计算法定人数
    quorum := q.calculateQuorum(len(nodes))

    // 4. 并行发送提案
    results := make(chan *QuorumVoteMessage, len(nodes))

    for _, node := range nodes {
        q.wg.Add(1)
        go func(addr string) {
            defer q.wg.Done()
            var vote *QuorumVoteMessage
            err := q.transport.SendAndReceive(ctx, addr, msg, &vote)
            if err != nil {
                vote = &QuorumVoteMessage{
                    ProposalID: proposalID,
                    NodeID:     addr,
                    Accepted:   false,
                }
            }
            results <- vote
        }(node)
    }

    // 5. 收集投票
    acceptCount := 1  // 自身投赞成票
    rejectCount := 0
    timeoutCh := time.After(q.config.Timeout)

    for i := 0; i < len(nodes); i++ {
        select {
        case vote := <-results:
            proposal.Votes[vote.NodeID] = vote.Accepted
            q.stats.VotesTotal.Add(1)

            if vote.Accepted {
                acceptCount++
                if acceptCount >= quorum {
                    proposal.Status = QuorumStatusAccepted
                    q.stats.ProposalsAccepted.Add(1)
                    return nil
                }
            } else {
                rejectCount++
                if rejectCount > len(nodes)-quorum {
                    proposal.Status = QuorumStatusRejected
                    q.stats.ProposalsRejected.Add(1)
                    return fmt.Errorf("提案被拒绝")
                }
            }

        case <-timeoutCh:
            proposal.Status = QuorumStatusRejected
            q.stats.ProposalsRejected.Add(1)
            return fmt.Errorf("提案超时")
        }
    }

    return nil
}
```

**Quorum 特性**：
- **并行投票**：同时发送到所有节点
- **快速决策**：达到多数派立即返回

- **法定人数**：N/2 + 1 保证多数派

```go
func (t *TwoPCService) preCommit(ctx context.Context, txn *TwoPCTransaction) error {
    txn.Status = TwoPCStatusPreCommit

    msg := &TwoPCPrepareMessage{
        TransactionID: txn.ID,
        Coordinator:   t.localNodeID,
        Operations:    txn.Operations,
    }

    // 并行发送预提交请求
    results := make(chan error, len(txn.Participants))

    for _, participant := range txn.Participants {
        t.wg.Add(1)
        go func(addr string) {
            defer t.wg.Done()

            var rep *TwoPCPrepareReplyMessage
            err := t.transport.SendAndReceive(ctx, addr, msg, &rep)
            if err != nil {
                results <- err
                return
            }

            if !rep.Accepted {
                results <- fmt.Errorf("预提交被拒绝")
                return
            }

            results <- nil
        }(participant)
    }

    // 等待所有响应
    for i := 0; i < len(txn.Participants); i++ {
        select {
        case err := <-results:
            if err != nil {
                return err
            }
        case <-ctx.Done():
            return ctx.Err()
        }
    }

    return nil
}
```

```go
        t.wg.Add(1)
        go func(addr string) {
            defer t.wg.Done()
            t.transport.Send(ctx, addr, msg)

    txn.Status = TwoPCStatusCommitted
    txn.EndTime = time.Now()

    return nil
```

```go
func (le *LeaderElection) selectLeader(candidates []*Node) *Node {
    var bestCandidate *Node
    var highestScore int64

    for _, candidate := range candidates {
        score := le.calculateScore(candidate)

        if score > highestScore {
            highestScore = score
            bestCandidate = candidate
        }
    }

    return bestCandidate

func (le *LeaderElection) calculateScore(node *Node) int64 {
    var score int64

    // 优先级权重（1000 为基础）
    score += int64(node.Priority) * 1000

    // 节点状态权重
    switch node.Status {
    case NodeStatusReady:
        score += 500
    case NodeStatusJoining:
        score += 200
    case NodeStatusInit:
        score += 100
    case NodeStatusLeaving:
        score += 50
    case NodeStatusFailed:
        score += 0
    }

    // 存活时间权重（最近的节点得分更高）
    uptime := time.Since(node.LastHeartbeat)
    if uptime < time.Minute {
        score += 100
    } else if uptime < 5*time.Minute {
        score += 50
    }

    return score
}
```

#### Phi 累加器算法

```go
func (fd *FailureDetector) computePhi(state *NodeState, elapsed time.Duration) float64 {
    var phi float64

    // 样本不足，使用简单的超时判断
    if len(state.HeartbeatIntervals) < fd.config.MinSamples {
        if elapsed > fd.config.Timeout {
            return 100.0
        }
        return 0.0
    }

    // 计算标准差
    if state.StdDev == 0 {
        return 0.0
    }

    // 计算 Φ 值
    elapsedMs := float64(elapsed.Milliseconds())
    deviation := elapsedMs - state.Mean
    phi = deviation / state.StdDev

    // Φ 值不能为负
    if phi < 0 {
        phi = 0
    }

    return phi
}
```

```go
func (fd *FailureDetector) RecordHeartbeat(nodeID string) {
    now := time.Now()

    fd.nodeStatesMu.Lock()
    defer fd.nodeStatesMu.Unlock()

    state, exists := fd.nodeStates[nodeID]
    if !exists {
        state = &NodeState{
            NodeID:             nodeID,
            HeartbeatIntervals: make([]float64, 0, fd.config.MinSamples),
        }
        fd.nodeStates[nodeID] = state
    }

    // 计算心跳间隔
    if !state.LastHeartbeat.IsZero() {
        interval := now.Sub(state.LastHeartbeat).Milliseconds()
        state.HeartbeatIntervals = append(state.HeartbeatIntervals, float64(interval))

        // 限制样本数量
        maxSamples := fd.config.MinSamples * 2
        if len(state.HeartbeatIntervals) > maxSamples {
            state.HeartbeatIntervals = state.HeartbeatIntervals[len(state.HeartbeatIntervals)-maxSamples:]
        }

        // 更新统计信息
        fd.updateStatistics(state)
    }

    state.LastHeartbeat = now

    // 如果节点之前被标记为故障，现在恢复
    if state.IsFailed.Load() {
        state.IsFailed.Store(false)
    }
}
```

```go
func (sh *SelfHealer) repairTopology(failedNodeID string) error {

    failedNode, err := sh.coordinator.GetNode(failedNodeID)
    if err != nil {

    allNodes := sh.coordinator.ListNodes()

    var bestScore int64

    for _, node := range allNodes {

            bestCandidate = node.NodeID
        }
```

## 9. 故障排查指南

### 9.1 常见问题诊断

#### 问题1：Gossip 收敛慢

**症状**：元数据变更长时间未同步

**诊断步骤**：
1. 检查 Gossip 同步间隔配置
2. 检查网络连接状态
3. 检查节点列表是否正确
4. 查看统计信息（同步次数、失败率）

**解决方案**：
```bash
# 调整同步间隔
# config.yaml
metadata:
  gossip_interval: "5s"  # 从 10s 减少到 5s

# 检查网络连接
telnet <node-addr> 9211

# 查看统计信息
curl http://localhost:9211/debug/stats
```

#### 问题2：Quorum 提案超时

**症状**：元数据变更频繁超时

**诊断步骤**：
1. 检查 Quorum 超时配置
2. 检查节点在线状态
3. 检查网络延迟
4. 查看统计信息（提案接受/拒绝率）

**解决方案**：
```bash
# 调整超时时间
# config.yaml
metadata:
  quorum_timeout: "60s"  # 从 30s 增加到 60s

# 检查节点状态
curl http://localhost:9211/debug/nodes
```

#### 问题3：时钟漂移过大

**症状**：Φ 值频繁超过阈值

**诊断步骤**：
1. 检查 NTP 同步状态
2. 检查时钟漂移统计
3. 检查网络延迟
4. 查看统计信息（最大/平均漂移）

**解决方案**：
```bash
# 检查 NTP 同步
ntpq -p

# 调整最大可接受漂移
# config.yaml
metadata:
  max_acceptable_drift: 5000  # 从 1000ms 增加到 5000ms
```

#### 问题4：WAL 文件过大

**症状**：WAL 文件占用过多磁盘空间

**诊断步骤**：
1. 检查 WAL 文件大小
2. 检查刷盘间隔配置
3. 检查快照生成频率

**解决方案**：
```bash
# 调整刷盘间隔
# config.yaml
metadata:
  flush_interval: "3s"  # 从 5s 减少到 3s

# 手动触发快照
curl -X POST http://localhost:9211/debug/snapshot
```
