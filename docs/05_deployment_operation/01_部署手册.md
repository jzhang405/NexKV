## 3. 配置说明

### 3.1 配置文件结构

**config.yaml**:
```yaml
# 集群配置
cluster:
  name: "nexkv-cluster"
  node:
    id: "node-1"          # 节点 ID(唯一)
    addr: "0.0.0.0:9211"  # 监听地址
  seed_nodes:
    - "node-1:9211"
    - "node-2:9211"
    - "node-3:9211"
  mode: "cluster"         # standalone | cluster

# 元数据配置
metadata:
  dir: "./data/metadata"
  gossip_interval: "10s"
  quorum_timeout: "30s"
  cache_size: 10000

# 存储配置
storage:
  data_dir: "./data/shards"
  wal_dir: "./data/wal"
  snapshot_interval: "1h"
  # WAL 保留时间（双层 WAL 架构）
  metadata_wal_retention: "720h"    # 元数据 WAL：30 天
  business_wal_retention: "2160h"   # 业务 WAL：90 天（3个月）

# 网络配置
network:
  listen_addr: "0.0.0.0:9211"
  max_connections: 1000
  keepalive_interval: "30s"
  read_timeout: "30s"
  write_timeout: "30s"

# 日志配置
logging:
  level: "info"            # debug | info | warn | error
  format: "json"           # json | text
  output: "./logs/nexkv.log"
  max_size: 100            # MB
  max_backups: 10
  max_age: 30              # days
```

## 4. 部署方式

### 4.1 本地开发环境部署

#### macOS

```bash
# 1. 编译项目
cd /path/to/NexKV
make build

# 2. 创建数据目录
mkdir -p data/{metadata,shards,wal}
mkdir -p logs

# 3. 启动单机模式
./bin/nexkv -config configs/single_node.yaml

# 4. 使用 CLI 连接
./bin/nexkv-cli -addr 127.0.0.1:9211 cluster list

# 5. 后台运行
nohup ./bin/nexkv -config configs/single_node.yaml > logs/nexkv.log 2>&1 &
```

---

#### Linux

```bash
# 1. 创建目录
mkdir -p /opt/nexkv/{bin,conf,data,logs}

# 2. 复制二进制
cp bin/nexkv /opt/nexkv/bin/
cp bin/nexkv-cli /opt/nexkv/bin/

# 3. 复制配置
cp configs/config.yaml /opt/nexkv/conf/

# 4. 创建用户
sudo useradd -r -s /bin/false nexkv
sudo chown -R nexkv:nexkv /opt/nexkv

# 5. 启动服务
sudo -u nexkv /opt/nexkv/bin/nexkv -config /opt/nexkv/conf/config.yaml
```

---

### 4.2 Systemd 服务 (Linux 生产环境)

**/etc/systemd/system/nexkv.service**:
```ini
[Unit]
Description=NexKV Distributed KV Store
After=network.target

[Service]
Type=simple
User=nexkv
Group=nexkv
ExecStart=/opt/nexkv/bin/nexkv -config /opt/nexkv/conf/config.yaml
Restart=always
RestartSec=5
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
```

**启动服务**:
```bash
# 重载 systemd
sudo systemctl daemon-reload

# 启动服务
sudo systemctl start nexkv

# 开机自启
sudo systemctl enable nexkv

# 查看状态
sudo systemctl status nexkv

# 查看日志
sudo journalctl -u nexkv -f
```

### 4.3 Docker 部署

**Dockerfile**:
```dockerfile
# 构建阶段
FROM golang:1.23-alpine AS builder

WORKDIR /build
COPY . .
RUN go build -o nexkv ./cmd/nexkv

# 运行阶段
FROM alpine:latest
RUN apk add --no-cache ca-certificates tzdata

WORKDIR /app
COPY --from=builder /build/nexkv .
COPY configs/config.yaml ./config.yaml

EXPOSE 9211

ENTRYPOINT ["./nexkv"]
CMD ["-config", "./config.yaml"]
```

**docker-compose.yml**:
```yaml
version: '3.8'

services:
  nexkv-1:
    build: .
    ports:
      - "9211:9211"
    volumes:
      - ./data/node-1:/app/data
      - ./logs/node-1:/app/logs
    environment:
      - NODE_ID=node-1
      - CLUSTER_NAME=nexkv-cluster
      - SEED_NODES=node-1:9211,node-2:9211,node-3:9211

  nexkv-2:
    build: .
    ports:
      - "9212:9211"
    volumes:
      - ./data/node-2:/app/data
      - ./logs/node-2:/app/logs
    environment:
      - NODE_ID=node-2
      - CLUSTER_NAME=nexkv-cluster
      - SEED_NODES=node-1:9211,node-2:9211,node-3:9211

  nexkv-3:
    build: .
    ports:
      - "9213:9211"
    volumes:
      - ./data/node-3:/app/data
      - ./logs/node-3:/app/logs
    environment:
      - NODE_ID=node-3
      - CLUSTER_NAME=nexkv-cluster
      - SEED_NODES=node-1:9211,node-2:9211,node-3:9211
```

**部署**:
```bash
# 构建镜像
docker build -t nexkv:latest .

# 启动集群
docker-compose up -d

# 查看日志
docker-compose logs -f nexkv-1
```

### 4.4 Kubernetes 部署

**deployment.yaml**:
```yaml
apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: nexkv
spec:
  serviceName: nexkv
  replicas: 3
  selector:
    matchLabels:
      app: nexkv
  template:
    metadata:
      labels:
        app: nexkv
    spec:
      containers:
      - name: nexkv
        image: nexkv:latest
        ports:
        - containerPort: 9211
          name: client
        env:
        - name: NODE_ID
          valueFrom:
            fieldRef:
              fieldPath: metadata.name
        - name: CLUSTER_NAME
          value: "nexkv-cluster"
        - name: SEED_NODES
          value: "nexkv-0.nexkv.default.svc.cluster.local:9211,nexkv-1.nexkv.default.svc.cluster.local:9211,nexkv-2.nexkv.default.svc.cluster.local:9211"
        volumeMounts:
        - name: data
          mountPath: /app/data
        - name: logs
          mountPath: /app/logs
        resources:
          requests:
            memory: "512Mi"
            cpu: "500m"
          limits:
            memory: "2Gi"
            cpu: "2000m"
  volumeClaimTemplates:
  - metadata:
      name: data
    spec:
      accessModes: ["ReadWriteOnce"]
      resources:
        requests:
          storage: 10Gi
---
apiVersion: v1
kind: Service
metadata:
  name: nexkv
spec:
  clusterIP: None
  ports:
  - port: 9211
    name: client
  selector:
    app: nexkv
---
apiVersion: v1
kind: Service
metadata:
  name: nexkv-client
spec:
  type: LoadBalancer
  ports:
  - port: 9211
    targetPort: 9211
  selector:
    app: nexkv
```

**部署**:
```bash
# 创建部署
kubectl apply -f deployment.yaml

# 查看状态
kubectl get pods -l app=nexkv
kubectl get svc

# 扩容
kubectl scale statefulset nexkv --replicas=5
```

## 6. 升级指南

### 6.1 滚动升级

```bash
# 1. 备份数据
./bin/nexkv-cli -addr node-1:9211 snapshot create

# 2. 逐个节点升级
for node in node-1 node-2 node-3; do
  echo "Upgrading $node..."

  # 停止节点
  ssh $node "sudo systemctl stop nexkv"

  # 替换二进制
  scp bin/nexkv $node:/opt/nexkv/bin/nexkv.new
  ssh $node "mv /opt/nexkv/bin/nexkv /opt/nexkv/bin/nexkv.old"
  ssh $node "mv /opt/nexkv/bin/nexkv.new /opt/nexkv/bin/nexkv"

  # 启动节点
  ssh $node "sudo systemctl start nexkv"

  # 等待节点就绪
  sleep 10
done
```

---

### 6.2 回滚

```bash
# 1. 停止节点

# 2. 恢复旧版本
mv /opt/nexkv/bin/nexkv /opt/nexkv/bin/nexkv.new
mv /opt/nexkv/bin/nexkv.old /opt/nexkv/bin/nexkv

# 3. 启动节点
sudo systemctl start nexkv

# 4. 验证
```

## 7. 安全加固

### 7.1 TLS 配置

```yaml
# config.yaml
network:
  tls:
    enabled: true
    cert_file: "/opt/nexkv/certs/server.crt"
    key_file: "/opt/nexkv/certs/server.key"
    ca_file: "/opt/nexkv/certs/ca.crt"
    client_auth:
      enabled: true
      ca_file: "/opt/nexkv/certs/client-ca.crt"
```

**生成证书**:
```bash
# 生成 CA
openssl genrsa -out ca-key.pem 2048
openssl req -x509 -new -nodes -key ca-key.pem -sha256 -days 3650 -out ca.pem -subj "/CN=NexKV CA"

# 生成服务器证书
openssl genrsa -out server-key.pem 2048
openssl req -new -key server-key.pem -out server.csr -subj "/CN=nexkv-server"
openssl x509 -req -in server.csr -CA ca.pem -CAkey ca-key.pem -CAcreateserial -out server.crt -days 365

# 生成客户端证书
openssl genrsa -out client-key.pem 2048
openssl req -new -key client-key.pem -out client.csr -subj "/CN=nexkv-client"
openssl x509 -req -in client.csr -CA ca.pem -CAkey ca-key.pem -CAcreateserial -out client.crt -days 365
```

## 9. 故障排查

### 9.1 节点无法启动

**症状**: 服务启动失败

**排查步骤**:
```bash
# 1. 查看详细日志
sudo journalctl -u nexkv -n 50 --no-pager

# 2. 检查端口占用
sudo lsof -i :9211

# 3. 验证配置文件
./bin/nexkv -config /opt/nexkv/conf/config.yaml -validate

# 4. 检查权限
sudo chown -R nexkv:nexkv /opt/nexkv
```

---

### 9.2 节点无法加入集群

**症状**: 节点启动后无法被发现

**排查步骤**:
```bash
# 1. 检查网络连通性
ping seed-node-addr
telnet seed-node-addr 9211

# 2. 检查防火墙
sudo iptables -L -n | grep 9211

# 3. 检查配置
# cluster.seed_nodes 必须包含正确的种子节点地址

# 4. 查看日志
sudo journalctl -u nexkv -f | grep "seed node"
```

---

### 9.3 性能问题

**症状**: 响应延迟高

**排查步骤**:
```bash
# 1. 查看 CPU 使用率
top -p $(pgrep nexkv)

# 2. 查看内存使用
free -h

# 3. CPU profiling
curl http://127.0.0.1:9211/debug/pprof/profile > cpu.prof
go tool pprof cpu.prof

# 4. 内存 profiling
curl http://127.0.0.1:9211/debug/pprof/heap > heap.prof
go tool pprof heap.prof
```
