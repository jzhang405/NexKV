## 1. 日常运维

### 1.1 服务管理

#### 启动和停止

```bash
# 启动服务
sudo systemctl start nexkv

# 停止服务
sudo systemctl stop nexkv

# 重启服务
sudo systemctl restart nexkv

# 查看状态
sudo systemctl status nexkv

# 查看是否开机自启
sudo systemctl is-enabled nexkv
```

---

#### 平滑重启

```bash
# 发送 TERM 信号，等待当前请求完成
sudo systemctl kill -s TERM nexkv

# 或者使用 CLI
./bin/nexkv-cli -addr 127.0.0.1:9211 server graceful-shutdown
```

---

### 1.2 日志管理

#### 日志查看

```bash
# 实时日志
sudo journalctl -u nexkv -f

# 最近 100 行
sudo journalctl -u nexkv -n 100

# 按时间过滤
sudo journalctl -u nexkv --since "1 hour ago"
sudo journalctl -u nexkv --since today

# 按级别过滤
sudo journalctl -u nexkv -p err
sudo journalctl -u nexkv -p warn
```

---

#### 日志轮转

```bash
# 手动触发日志轮转
./bin/nexkv-cli -addr 127.0.0.1:9211 logging rotate

# 查看日志文件
ls -lh /opt/nexkv/logs/
```

---

#### 日志分析

```bash
# 统计错误数量
sudo journalctl -u nexkv --since "1 hour ago" -p err | wc -l

# 查找特定错误
sudo journalctl -u nexkv | grep -i "connection refused"

# 时间段统计
sudo journalctl -u nexkv --since "00:00" --until "23:59" | grep "ERROR" | wc -l
```

---

### 1.3 配置管理

#### 配置查看

```bash
# 查看所有配置
./bin/nexkv-cli -addr 127.0.0.1:9211 config get-all

# 查看特定配置
./bin/nexkv-cli -addr 127.0.0.1:9211 config get metadata.gossip_interval

# 查看默认配置
./bin/nexkv-cli -addr 127.0.0.1:9211 config get-default metadata.gossip_interval
```

---

#### 配置修改

```bash
# 修改配置（热更新）
./bin/nexkv-cli -addr 127.0.0.1:9211 config set metadata.gossip_interval 5s

# 重置为默认值
./bin/nexkv-cli -addr 127.0.0.1:9211 config reset metadata.gossip_interval

# 批量修改
./bin/nexkv-cli -addr 127.0.0.1:9211 config set-file new-config.yaml
```

---

### 1.4 节点管理

#### 节点状态

```bash
# 查看集群节点列表
./bin/nexkv-cli -addr 127.0.0.1:9211 cluster list

# 查看节点状态
./bin/nexkv-cli -addr 127.0.0.1:9211 cluster status node-1

# 查看集群拓扑
./bin/nexkv-cli -addr 127.0.0.1:9211 cluster topology
```

---

#### 节点操作

```bash
# 添加节点
./bin/nexkv-cli -addr 127.0.0.1:9211 cluster add node-4 192.168.1.14:9211

# 移除节点
./bin/nexkv-cli -addr 127.0.0.1:9211 cluster remove node-4

# 节点隔离（维护模式）
./bin/nexkv-cli -addr 127.0.0.1:9211 cluster isolate node-4

# 节点恢复
./bin/nexkv-cli -addr 127.0.0.1:9211 cluster resume node-4
```

## 2. 监控告警

### 2.1 Prometheus 指标

#### 指标采集

```bash
# 访问 metrics 端点
curl http://127.0.0.1:9211/metrics

# 查看特定指标
curl http://127.0.0.1:9211/metrics | grep nexkv_
```

---

#### 完整监控指标列表

**1. 吞吐量指标（Throughput）**

| 指标名称 | 类型 | 说明 | 关键标签 |
|---------|------|------|---------|
| `nexkv_requests_total` | Counter | 总请求数 | operation, status |
| `nexkv_requests_qps` | Gauge | 当前 QPS | operation, node |
| `nexkv_metadata_ops_total` | Counter | 元数据操作总数 | op_type（create/update/delete/query） |
| `nexkv_data_reads_total` | Counter | 数据读取总数 | shard, replica |
| `nexkv_data_writes_total` | Counter | 数据写入总数 | shard, replica |
| `nexkv_transactions_total` | Counter | 事务总数 | status（committed/rollback） |
| `nexkv_transactions_tps` | Gauge | 当前 TPS | node |

**使用示例**：
```promql
# 总 QPS
sum(rate(nexkv_requests_total[5m]))

# 读写 QPS
sum(rate(nexkv_data_reads_total[5m])) by (shard)
sum(rate(nexkv_data_writes_total[5m])) by (shard)

# 事务 TPS
sum(rate(nexkv_transactions_total{status="committed"}[5m]))
```

**2. 延迟指标（Latency）**

| 指标名称 | 类型 | 说明 | 关键标签 | 分位数 |
|---------|------|------|---------|--------|
| `nexkv_request_duration_seconds` | Histogram | 请求延迟 | operation, shard | P50/P95/P99 |
| `nexkv_metadata_latency_seconds` | Histogram | 元数据请求延迟 | op_type | P50/P95/P99 |
| `nexkv_storage_read_latency_seconds` | Histogram | 存储读取延迟 | shard | P50/P95/P99 |
| `nexkv_storage_write_latency_seconds` | Histogram | 存储写入延迟 | shard | P50/P95/P99 |
| `nexkv_gossip_sync_seconds` | Histogram | Gossip 同步延迟 | peer | P95/P99 |
| `nexkv_quorum_decision_seconds` | Histogram | Quorum 决策延迟 | shard | P95/P99 |
| `nexkv_2pc_duration_seconds` | Histogram | 2PC 事务延迟 | phase | P50/P95/P99 |

**延迟告警阈值**：
| 操作 | P50 目标 | P95 目标 | P99 目标 |
|------|---------|---------|---------|
| 元数据查询 | < 1ms | < 5ms | < 10ms |
| 元数据更新 | < 5ms | < 20ms | < 50ms |
| 数据读取 | < 2ms | < 10ms | < 20ms |
| 数据写入 | < 5ms | < 20ms | < 50ms |
| Gossip 同步 | < 1s | < 5s | < 10s |
| Quorum 决策 | < 10ms | < 50ms | < 100ms |
| 2PC 事务 | < 50ms | < 200ms | < 500ms |

**使用示例**：
```promql
# P95 读取延迟
histogram_quantile(0.95, sum(rate(nexkv_storage_read_latency_seconds_bucket[5m])) by (le, shard))

# P95 写入延迟
histogram_quantile(0.95, sum(rate(nexkv_storage_write_latency_seconds_bucket[5m])) by (le, shard))

# 平均延迟
rate(nexkv_request_duration_seconds_sum[5m]) / rate(nexkv_request_duration_seconds_count[5m])
```

### 2.3 告警规则

#### 告警配置

**alerts.yml**:
```yaml
groups:
  - name: nexkv_alerts
    rules:
      # === 服务可用性告警 ===
      - alert: NexKVNodeDown
        expr: nexkv_node_up == 0
        for: 1m
        labels:
          severity: critical
        annotations:
          summary: "NexKV node {{ $labels.instance }} is down"
          description: "Node has been down for more than 1 minute"

      - alert: NexKVNodeUnhealthy
        expr: nexkv_node_healthy == 0
        for: 2m
        labels:
          severity: warning
        annotations:
          summary: "NexKV node {{ $labels.instance }} is unhealthy"
          description: "Node health check failing"

      # === 吞吐量告警 ===
      - alert: NexKVLowQPS
        expr: sum(rate(nexkv_requests_total[5m])) by (node) < 100
        for: 10m
        labels:
          severity: warning
        annotations:
          summary: "NexKV low QPS detected"
          description: "QPS is {{ $value }} on {{ $labels.instance }}"

      - alert: NexKVHighErrorRate
        expr: sum(rate(nexkv_requests_errors_total[5m])) / sum(rate(nexkv_requests_total[5m])) > 0.05
        for: 5m
        labels:
          severity: critical
        annotations:
          summary: "NexKV high error rate detected"
          description: "Error rate is {{ $value | humanizePercentage }}"

      # === 延迟告警 ===
      - alert: NexKVHighLatency
        expr: histogram_quantile(0.95, rate(nexkv_request_duration_seconds_sum[5m]) / rate(nexkv_request_duration_seconds_count[5m])) > 0.1
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "NexKV high latency detected"
          description: "P95 latency is {{ $value }}s on {{ $labels.instance }}"

      - alert: NexKVHighP99Latency
        expr: histogram_quantile(0.99, rate(nexkv_request_duration_seconds_sum[5m]) / rate(nexkv_request_duration_seconds_count[5m])) > 0.5
        for: 5m
        labels:
          severity: critical
        annotations:
          summary: "NexKV critical latency detected"
          description: "P99 latency is {{ $value }}s on {{ $labels.instance }}"

      # === 一致性协议告警 ===
      - alert: NexKVGossipSlow
        expr: nexkv_gossip_convergence_seconds{priority="critical"} > 5
        for: 5m
        labels:
          severity: critical
        annotations:
          summary: "Critical Gossip convergence is slow"
          description: "Critical Gossip sync taking {{ $value }}s"

      - alert: NexKVGossipSlowNormal
        expr: nexkv_gossip_convergence_seconds{priority="normal"} > 30
        for: 10m
        labels:
          severity: warning
        annotations:
          summary: "Normal Gossip convergence is slow"
          description: "Normal Gossip sync taking {{ $value }}s"

      - alert: NexKVQuorumFailureRate
        expr: sum(rate(nexkv_quorum_failure_total[5m])) / (sum(rate(nexkv_quorum_success_total[5m])) + sum(rate(nexkv_quorum_failure_total[5m]))) > 0.05
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "High Quorum failure rate detected"
          description: "Quorum failure rate is {{ $value | humanizePercentage }}"

      - alert: NexKV2PCHighTimeoutRate
        expr: sum(rate(nexkv_2pc_timeout_total[5m])) / sum(rate(nexkv_transactions_total[5m])) > 0.03
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "High 2PC timeout rate detected"
          description: "2PC timeout rate is {{ $value | humanizePercentage }}"

      # === 存储告警 ===
      - alert: NexKVDiskSpaceLow
        expr: nexkv_storage_utilization > 0.9
        for: 5m
        labels:
          severity: critical
        annotations:
          summary: "Disk space is critically low"
          description: "Storage usage is {{ $value | humanizePercentage }}"

      - alert: NexKVDiskSpaceWarning
        expr: nexkv_storage_utilization > 0.8
        for: 10m
        labels:
          severity: warning
        annotations:
          summary: "Disk space is low"
          description: "Storage usage is {{ $value | humanizePercentage }}"

      - alert: NexKVWALSizeHigh
        expr: nexkv_wal_size_bytes > 2GB
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "WAL file size is high"
          description: "WAL size is {{ $value | humanize }}"

      - alert: NexKVLowCacheHitRate
        expr: nexkv_mvstore_cache_hit_rate < 0.7
        for: 10m
        labels:
          severity: warning
        annotations:
          summary: "MVStore cache hit rate is low"
          description: "Cache hit rate is {{ $value | humanizePercentage }}"

      # === 副本同步告警 ===
      - alert: NexKVReplicaLag
        expr: nexkv_replica_lag_bytes > 1GB
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "Replica lag is high"
          description: "Replica lag is {{ $value | humanize }} on {{ $labels.shard }}"

      - alert: NexKVReplicaOutOfSync
        expr: sum(nexkv_replica_status{status="out_of_sync"}) by (shard) > 0
        for: 2m
        labels:
          severity: critical
        annotations:
          summary: "Replica is out of sync"
          description: "{{ $value }} replica(s) out of sync on {{ $labels.shard }}"

      # === 资源使用告警 ===
      - alert: NexKVHighCPU
        expr: nexkv_cpu_usage_percent > 90
        for: 10m
        labels:
          severity: critical
        annotations:
          summary: "CPU usage is critically high"
          description: "CPU usage is {{ $value }}%"

      - alert: NexKVHighMemory
        expr: nexkv_memory_usage_percent > 95
        for: 5m
        labels:
          severity: critical
        annotations:
          summary: "Memory usage is critically high"
          description: "Memory usage is {{ $value }}%"

      - alert: NexKVHighGoroutines
        expr: nexkv_goroutine_count > 5000
        for: 10m
        labels:
          severity: warning
        annotations:
          summary: "Too many goroutines"
          description: "Goroutine count is {{ $value }}"

      # === 网络分区告警 ===
      - alert: NexKVNetworkPartitionDetected
        expr: sum(nexkv_network_partition_detected) > 0
        for: 0m
        labels:
          severity: critical
        annotations:
          summary: "Network partition detected"
          description: "Network partition detected on {{ $labels.node }}"

      # === 版本向量漂移告警 ===
      - alert: NexKVVersionVectorDrift
        expr: nexkv_version_vector_drift > 50
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "Version vector drift detected"
          description: "Version vector drift is {{ $value }} on {{ $labels.node }}"
```

## 4. 故障处理

### 4.1 常见故障

#### 节点无响应

**症状**: 节点状态显示为 Suspect 或 Dead

**处理步骤**:
```bash
# 1. 检查进程状态
sudo systemctl status nexkv

# 2. 检查网络连通性
ping node-addr
telnet node-addr 9211

# 3. 检查资源使用
top -p $(pgrep nexkv)
free -h

# 4. 查看日志
sudo journalctl -u nexkv -n 100

# 5. 尝试重启
sudo systemctl restart nexkv
```

---

#### 数据不一致

**症状**: 不同节点数据不一致

**处理步骤**:
```bash
# 1. 查看版本号
./bin/nexkv-cli -addr node-1:9211 version get
./bin/nexkv-cli -addr node-2:9211 version get

# 2. 手动触发 Gossip 同步
./bin/nexkv-cli -addr node-1:9211 gossip sync node-2:9211

# 3. 查看变更日志
./bin/nexkv-cli -addr node-1:9211 changelog list --since 0

# 4. 强制同步
./bin/nexkv-cli -addr node-1:9211 cluster sync

# 5. 如果仍不一致，从快照恢复
./bin/nexkv-cli -addr node-1:9211 snapshot restore latest
```

---

#### 性能下降

**症状**: 响应延迟明显增加

**处理步骤**:
```bash
# 1. 查看 profiling 数据
curl http://127.0.0.1:9211/debug/pprof/heap > heap.prof
go tool pprof heap.prof

# 2. 查看 goroutine 数量
curl http://127.0.0.1:9211/debug/pprof/goroutine?debug=1

# 3. 查看 CPU profile
curl http://127.0.0.1:9211/debug/pprof/profile?seconds=30 > cpu.prof
go tool pprof cpu.prof

# 4. 检查磁盘 I/O
iostat -x 1

# 5. 检查网络延迟
ping node-addr
mtr node-addr
```

---

### 4.2 应急处理

#### 紧急停机

```bash
# 立即停止服务（数据可能丢失）
sudo systemctl kill nexkv

# 或发送 SIGKILL
sudo kill -9 $(pgrep nexkv)
```

---

#### 紧急回滚

```bash
# 1. 停止服务

# 2. 恢复旧版本二进制

# 3. 恢复配置
mv /opt/nexkv/conf/config.yaml /opt/nexkv/conf/config.new
mv /opt/nexkv/conf/config.yaml.old /opt/nexkv/conf/config.yaml

# 4. 从备份恢复

```
