## 2. 技术方案

### 2.1 修复 globalClusterService 无锁保护

**问题位置**：`internal/rpc/quorum.go:263`

**当前代码**：
```go
var globalClusterService ClusterService

func SetClusterService(service ClusterService) {
    globalClusterService = service  // ❌ 无锁保护
}

func GetClusterService() ClusterService {
    return globalClusterService  // ❌ 无锁保护
}
```

**修复方案（atomic.Value）**：
```go
var globalClusterService atomic.Value

func SetClusterService(service ClusterService) {
    globalClusterService.Store(service)
}

func GetClusterService() ClusterService {
    v := globalClusterService.Load()
    if v == nil {
        return nil  // ✅ nil 安全：未初始化时返回 nil
    }
    return v.(ClusterService)
}
```

**选择理由**：
- `atomic.Value` 支持多次读写（非真正单例场景）
- 无锁操作，性能优于 RWMutex
- 允许运行时动态更新服务
- 原子操作保证并发安全

**nil 安全处理**（架构师要求）：
- `Load()` 可能返回 nil（未初始化时）
- 必须先检查 nil 再进行类型断言，否则会 panic
- 调用处也需要处理 nil 情况：

```go
// 在调用 GetClusterService() 的地方需要 nil 检查
service := GetClusterService()
if service == nil {
    return errors.New("cluster service not initialized")
}
// 使用 service...
```

**方案对比**：
| 方案 | 适用场景 |
|------|----------|
| `sync.Once` | 真正的单例（只初始化一次） |
| `sync.RWMutex` | 读多写少，有锁开销 |
| `atomic.Value` | ✅ 推荐：频繁读写，无锁，支持更新 |

### 2.2 修复 globalRequestID 非原子操作

**问题位置**：`internal/rpc/client.go:19`

**当前代码**：
```go
var globalRequestID uint64

func nextRequestID() uint64 {
    globalRequestID++  // ❌ 非原子操作
    return globalRequestID
}
```

**修复方案**：
```go
var globalRequestID uint64

func nextRequestID() uint64 {
    return atomic.AddUint64(&globalRequestID, 1)
}
```

**选择理由**：
- `atomic.AddUint64()` 是原子操作，保证并发安全
- 返回值就是递增后的值，无需再读取
- 性能优于锁机制

### 2.3 实现 initLogging 完整功能

**问题位置**：`cmd/nexkvd/main.go:432`

**当前代码**：
```go
func initLogging(logLevel string) error {
    // TODO: 实现完整的日志初始化
    level := "info"
    if logLevel != "" {
        level = logLevel
    }
    _ = level // 占位，后续实现
    return nil
}
```

**日志包 API 确认**（`internal/config/logging/logger.go`）：
- 使用 `github.com/sirupsen/logrus` 作为底层日志库
- `Init(logger *logrus.Logger)` - 初始化全局日志
- `GetLogger() *logrus.Logger` - 获取日志实例（单例模式）
- `WithField/WithFields` - 结构化日志
- `Debug/Info/Warn/Error/Fatal` - 各级别日志

**修复方案**：
```go
func initLogging(logLevel string) error {
    level := "info"
    if logLevel != "" {
        level = strings.ToLower(logLevel)
    }

    // 创建新的 logger 实例
    logger := logrus.New()

    // 设置日志级别
    switch level {
    case "debug":
        logger.SetLevel(logrus.DebugLevel)
    case "info":
        logger.SetLevel(logrus.InfoLevel)
    case "warn", "warning":
        logger.SetLevel(logrus.WarnLevel)
    case "error":
        logger.SetLevel(logrus.ErrorLevel)
    default:
        logger.SetLevel(logrus.InfoLevel)
    }

    // 设置日志格式（JSON 格式便于解析）
    logger.SetFormatter(&logrus.JSONFormatter{
        TimestampFormat: "2006-01-02 15:04:05",
    })

    logger.SetOutput(os.Stdout)

    // 初始化全局日志
    logging.Init(logger)

    logging.Infof("日志系统初始化完成，级别: %s", level)
    return nil
}
```

**注意事项**：
- 使用 logrus 而非标准库 log
- JSON 格式便于日志收集和解析
- 保持与现有 logging 包 API 的兼容性

### 2.4 修复 NodeAddress 双重定义

**问题分析**：
- `internal/metadata/types/node_info.go:34` 定义了 NodeAddress（有 msgpack 标签）
- `internal/metadata/cluster/tree_coordinator.go:66` 定义了 NodeAddress（有 TCPAddr/UDPAddr 方法）

**两个定义的差异**：

| 特性 | types.NodeAddress | cluster.NodeAddress |
|------|------------------|-------------------|
| msgpack 序列化标签 | ✅ 有 | ❌ 无 |
| TCPAddr() 方法 | ❌ 无 | ✅ 有 |
| UDPAddr() 方法 | ❌ 无 | ✅ 有 |

**修复方案**：
1. 将 `cluster.NodeAddress` 的方法（TCPAddr、UDPAddr）迁移到 `types.NodeAddress`
2. 统一使用 `types.NodeAddress`
3. 更新 cluster 包中的引用
4. 删除 `cluster.NodeAddress` 定义

**实施步骤**：
1. 复制 `TCPAddr()` 和 `UDPAddr()` 方法到 `types/node_info.go`
2. 更新 `tree_coordinator.go` 中所有 `NodeAddress` 引用为 `types.NodeAddress`
3. 删除 `cluster.NodeAddress` 定义（tree_coordinator.go:66-74）
4. 添加对应的 import 路径调整
5. 编译验证无类型冲突

func TestGlobalClusterServiceConcurrency(t *testing.T) {
    var wg sync.WaitGroup
    for i := 0; i < 1000; i++ {
        wg.Add(1)
        go func() {
            defer wg.Done()
            // 并发写入
            SetClusterService(&mockClusterService{})
            // 并发读取

            if svc == nil {
                t.Error("GetClusterService returned nil")
            }
        }()
    }
    wg.Wait()
}

// TestRequestIDUniqueness ID 唯一性测试
func TestRequestIDUniqueness(t *testing.T) {
    var mu sync.Mutex
    idMap := make(map[uint64]bool)
    var wg sync.WaitGroup

    for i := 0; i < 10000; i++ {
        wg.Add(1)
        go func() {
            defer wg.Done()
            id := nextRequestID()
            mu.Lock()
            defer mu.Unlock()
            if idMap[id] {
                t.Errorf("Duplicate ID: %d", id)
            }
            idMap[id] = true
        }()
    }
    wg.Wait()

    // 验证 ID 连续且无重复
    if len(idMap) != 10000 {
        t.Errorf("Expected 10000 unique IDs, got %d", len(idMap))
    }
}
