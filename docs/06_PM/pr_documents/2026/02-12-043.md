## 2. 问题分析

### 2.1 P0-1: globalClusterService 无并发保护

**位置**: `internal/rpc/quorum.go:263`

**问题描述**:
```go
// 全局变量，无并发保护
var globalClusterService ClusterService
```

**影响**:
- 多个 goroutine 同时访问可能导致数据竞争
- 高并发场景下可能崩溃
- 数据不一致风险

**修复方案**:
使用 `sync.RWMutex` 保护全局变量访问：
```go
var (
    globalClusterService    ClusterService
    globalClusterServiceMu sync.RWMutex
)

func GetClusterService() ClusterService {
    globalClusterServiceMu.RLock()
    defer globalClusterServiceMu.RUnlock()
    return globalClusterService
}

func SetClusterService(s ClusterService) {
    globalClusterServiceMu.Lock()
    defer globalClusterServiceMu.Unlock()
    globalClusterService = s
}
```

### 2.2 P0-2: globalRequestID 非原子操作

**位置**: `internal/rpc/client.go:19`

**问题描述**:
```go
// 全局变量，非原子递增
var globalRequestID uint64

func nextRequestID() uint64 {
    globalRequestID++
    return globalRequestID
}
```

**影响**:
- 并发请求可能生成相同 ID
- 导致 RPC 响应错乱

**修复方案**:
使用 `atomic.AddUint64` 保证原子性：
```go
var globalRequestID uint64

func nextRequestID() uint64 {
    return atomic.AddUint64(&globalRequestID, 1)
}
```

### 2.3 Phase 0: Quorum 协议初始节点选择

**问题描述**:
Quorum 协议在 Phase 0 (初始化阶段) 可能遇到：
- 节点状态未 Ready 时尝试通信
- 节点列表为空时的处理不当

**影响**:
- 集群启动时 Quorum 请求失败
- 节点加入过程可能阻塞

**修复方案**:
1. 在 Phase 0 阶段过滤非 Ready 节点
2. 添加节点就绪状态检查
3. 实现 Quorum 超时和重试机制

## 3. 技术设计

### 3.1 并发安全设计

#### 全局变量保护模式

```go
// 模式：读写锁保护的全局变量
type ProtectedGlobal struct {
    value  ClusterService
    mu     sync.RWMutex
}

func (pg *ProtectedGlobal) Get() ClusterService {
    pg.mu.RLock()
    defer pg.mu.RUnlock()
    return pg.value
}

func (pg *ProtectedGlobal) Set(value ClusterService) {
    pg.mu.Lock()
    defer pg.mu.Unlock()
    pg.value = value
}
```

#### 原子操作模式

```go
// 使用 atomic 包保证原子性
type AtomicRequestID struct {
    id uint64
}

func (a *AtomicRequestID) Next() uint64 {
    return atomic.AddUint64(&a.id, 1)
}
```

### 3.2 Phase 0 处理设计

#### Quorum Phase 状态机

```go
type QuorumPhase int

const (
    Phase0Init      QuorumPhase = iota // 初始化阶段
    Phase1NodeSelection              // 节点选择阶段
    Phase2Request                    // 请求阶段
    Phase3Response                   // 响应阶段
)

// 处理 Phase 0 的节点过滤
func (q *QuorumCoordinator) filterReadyNodes(nodes []*Node) []*Node {
    var ready []*Node
    for _, node := range nodes {
        if node.Status == NodeStatusReady {
            ready = append(ready, node)
        }
    }
    return ready
}
```
