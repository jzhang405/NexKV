### 2. 协议设计（90% 完成）

#### 2.1 TLV 帧格式（100% 完成）

```
┌─────────────────┬─────────┬─────────┬─────────┐
│ Frame Header    │ TLV #1  │ TLV #2  │ TLV #N  │
├─────────────────┼─────────┼─────────┼─────────┤
│ MsgType (1B)    │ Type    │ Type    │ Type    │
│ CodecID (1B)    │ Length  │ Length  │ Length  │
│ MsgID (8B)      │ Value   │ Value   │ Value   │
│ Payload (N)     │         │         │         │
└─────────────────┴─────────┴─────────┴─────────┘
```

**已实现的 TLV 扩展字段**:
- ✅ HopCount (0x01) - 跳数限制，防止消息环路
- ✅ Compression (0x02) - Snappy/ZSTD/LZ4 压缩
- ✅ DeepCopy (0x03) - 深拷贝标记
- ✅ TraceID (0x04) - 分布式追踪支持

#### 2.2 UDP 分片协议（95% 完成）

**协议特性**:
- ✅ 自动分片：支持最大 100MB 消息
- ✅ 分片重组：接收端自动重组
- ✅ 位图跟踪：PR-020 新增，不依赖到达顺序
- ✅ 超时清理：快照遍历优化 + 结构化日志

**剩余缺口**:
- ⚠️ NACK 机制：未实现（长期优化方向）
- ⚠️ 动态窗口：未实现（类 TCP 拥塞控制）
