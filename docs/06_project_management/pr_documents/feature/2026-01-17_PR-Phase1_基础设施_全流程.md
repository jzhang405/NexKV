### 2. 背景与目标

#### 2.1 背景
- **业务场景**：分布式系统需要全局唯一 ID 和逻辑时钟
- **价值**：支持分布式事务和事件排序

#### 2.2 核心目标
1. **功能目标**：
   - 实现 HLC（混合逻辑时钟）
   - 实现 UUID v7 生成器
2. **性能目标**：
   - HLC 更新延迟：< 1 μs
   - UUID 生成速度：> 1000000 IDs/s

### 3. 实现方案

```go
type HLC struct {
    physical int64  // 物理时钟（毫秒）
    logical  int64  // 逻辑时钟
}

type UUIDGenerator interface {
    Generate() string
}
```
