## 2. 技术方案

### 2.1 修复 globalClusterService 无锁保护

**问题位置**：`internal/rpc/quorum.go:263`

**当前代码**：
```go
var globalClusterService ClusterService

func SetClusterService(service ClusterService) {
    globalClusterService = service  // ❌ 无锁保护
}

func GetClusterService() ClusterService {
    return globalClusterService  // ❌ 无锁保护
}
```

**修复方案（atomic.Value）**：
```go
var globalClusterService atomic.Value

func SetClusterService(service ClusterService) {
    globalClusterService.Store(service)
}

func GetClusterService() ClusterService {
    v := globalClusterService.Load()
    if v == nil {
        return nil
    }
    return v.(ClusterService)
}
```

**选择理由**：
- `atomic.Value` 支持多次读写（非真正单例场景）
- 无锁操作，性能优于 RWMutex
- 允许运行时动态更新服务
- 原子操作保证并发安全

**方案对比**：
| 方案 | 适用场景 |
|------|----------|
| `sync.Once` | 真正的单例（只初始化一次） |
| `sync.RWMutex` | 读多写少，有锁开销 |
| `atomic.Value` | ✅ 推荐：频繁读写，无锁，支持更新 |

### 2.2 修复 globalRequestID 非原子操作

**问题位置**：`internal/rpc/client.go:19`

**当前代码**：
```go
var globalRequestID uint64

func nextRequestID() uint64 {
    globalRequestID++  // ❌ 非原子操作
    return globalRequestID
}
```

**修复方案**：
```go
var globalRequestID uint64

func nextRequestID() uint64 {
    return atomic.AddUint64(&globalRequestID, 1)
}
```

**选择理由**：
- `atomic.AddUint64()` 是原子操作，保证并发安全
- 返回值就是递增后的值，无需再读取
- 性能优于锁机制

### 2.3 实现 initLogging 完整功能

**问题位置**：`cmd/nexkvd/main.go:432`

**当前代码**：
```go

    level := "info"

    }
    _ = level // 占位，后续实现

```

**修复方案**（需要先确认项目使用的日志包）：
```go
func initLogging(logLevel string) error {
    level := "info"
    if logLevel != "" {
        level = strings.ToLower(logLevel)
    }

    // 设置日志级别（根据实际使用的日志包调整）
    switch level {
    case "debug":
        logging.SetLevel(logging.DebugLevel)
    case "info":
        logging.SetLevel(logging.InfoLevel)
    case "warn", "warning":
        logging.SetLevel(logging.WarnLevel)
    case "error":
        logging.SetLevel(logging.ErrorLevel)
    default:
        logging.SetLevel(logging.InfoLevel)
    }

    // 设置日志格式
    logging.SetFormatter(&logging.TextFormatter{
        FullTimestamp:   true,
        TimestampFormat: "2006-01-02 15:04:05",
    })

    logging.Infof("日志系统初始化完成，级别: %s", level)
    return nil
}
```
