## 一、培训总览

### 培训目标

1. ✅ 理解 DDD 5层架构设计理念和依赖倒置原则

3. ✅ 熟悉 libp2p 去中心化通信和局域网节点发现

## 二、培训内容

### Day 1 上午：DDD 架构原则（3小时）

**培训内容**:
1. DDD 领域驱动设计概述
2. NexKV 5层架构设计
3. 依赖倒置原则（DIP）
4. 聚合根和领域事件设计
5. 接口与实现分离

**培训目标**:
- 理解为什么要用 DDD 架构
- 掌握 5层架构的层次关系
- 理解依赖倒置的重要性
- 学会设计聚合根和领域事件

**详细文档**: `2026-02-18_Day1-AM-DDD-Architecture.md`

---

### Day 1 下午：Go 泛型编程（3小时）

**培训内容**:
1. Go 1.18+ 泛型语法
2. 类型参数和约束
3. AsyncOperation[T] 接口设计
4. 泛型实战：Future/Callback/Channel 模式
5. 性能优化和最佳实践

**培训目标**:
- 掌握 Go 泛型基本语法
- 理解类型约束和推断
- 学会设计泛型接口
- 掌握 AsyncOperation[T] 的三种模式

**详细文档**: `2026-02-18_Day1-PM-Go-Generics.md`

---

### Day 2-3：libp2p 基础（1天，6小时）

**培训内容**:
1. libp2p 去中心化通信原理
2. mDNS 节点发现（局域网）
3. Stream 多路复用
4. RPC 调用和消息编解码
5. 实践：编写 libp2p Hello World 程序

**培训目标**:
- 理解去中心化通信的优势
- 掌握 mDNS 节点发现机制
- 学会使用 Stream 多路复用
- 能够编写基本的 libp2p 程序

**详细文档**: `2026-02-18_Day2-3-libp2p-Basics.md`

**实践代码**: `examples/libp2p-helloworld/`

---

### Day 4-5：Bf-Tree 原理（1天，6小时）

**培训内容**:
1. Bf-Tree 数据结构
2. WAL 写入机制
3. 性能优势分析（比传统 BTree 快 1.7-3.3x）
4. 内存管理和快照
5. 移植到 Go 的挑战

**培训目标**:
- 理解 Bf-Tree 的核心创新
- 掌握 WAL 写入机制
- 理解性能优势的来源
- 了解移植到 Go 的技术挑战

**详细文档**: `2026-02-18_Day4-5-BfTree-Principles.md`

## 三、培训流程

### 培训前准备

**培训师准备**:
- [ ] 准备培训 PPT 和文档
- [ ] 准备示例代码
- [ ] 准备测试题
- [ ] 准备签到表

**学员准备**:
- [ ] 安装 Go 1.21+ 环境
- [ ] 安装 IDE（推荐 VS Code 或 GoLand）
- [ ] 克隆 NexKV 项目
- [ ] 预读 Pre 文档 v1.5

---

### 培训执行

**每天流程**:
1. **09:00-09:10**: 签到（10分钟）
2. **09:10-10:30**: 理论讲解（80分钟）
3. **10:30-10:45**: 休息（15分钟）
4. **10:45-12:00**: 理论讲解 + 讨论（75分钟）
5. **12:00-13:30**: 午休（90分钟）
6. **13:30-14:50**: 实践/案例分析（80分钟）
7. **14:50-15:05**: 休息（15分钟）
8. **15:05-16:30**: 实践/案例分析（85分钟）
9. **16:30-17:00**: 总结 + Q&A（30分钟）

---

### 培训后评估

**评估方式**:
1. **培训后测试**: 20道选择题 + 4道简答题（60分钟）
2. **通过标准**: 正确率 ≥ 80%
3. **补考机制**: 未通过者可补考一次

**测试内容分布**:
- DDD 架构原则: 5题
- Go 泛型编程: 5题
- libp2p 基础: 5题
- Bf-Tree 原理: 5题
- 简答题: 4题（每个主题1题）
