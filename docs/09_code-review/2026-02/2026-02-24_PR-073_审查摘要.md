### ⚠️ 需要修复的问题

#### P1-01: 测试失败（阻塞合并）

**影响**: 5 个测试失败，92% 通过率

**失败测试**:
1. `TestNewOp_Discard` - 竞态条件导致状态检查失败
2. `TestNewOp_OnComplete` - 回调未被执行
3. `TestNewOp_OnCompleteAfterCompletion` - 回调未立即执行
4. `TestNewGroup_Callback` - 回调计数不准
5. `ExampleNewGroup_withCallback` - 示例输出不匹配

**根本原因**:
- 测试使用 `time.Sleep` 等待状态，在并发环境下不稳定
- 回调注册时机与任务完成时机存在竞态
- 回调在锁外异步执行，测试提前检查导致计数不准

**修复建议**:
```go
// 1. 使用 channel 同步替代 time.Sleep
started := make(chan struct{})
op := NewOp(ctx, nil, func(ctx context.Context) (string, error) {
    close(started) // 通知任务已启动
    time.Sleep(200 * time.Millisecond)
    return "should be discarded", nil
})
<-started // 等待任务启动

// 2. 回调测试使用 WaitGroup 同步
var wg sync.WaitGroup
wg.Add(len(targets))
callback := &testCallback{
    onSuccess: func(...) {
        defer wg.Done()
        // ...
    },
}
group.SetCallback(callback)
wg.Wait() // 等待所有回调完成
```

#### P1-02: AsyncOp.execute 缺少 Panic 恢复

**影响**: 用户代码 panic 会导致 goroutine 泄漏

**问题代码**:
```go
// async_op.go:240-287
func (op *AsyncOp[T]) execute(ctx context.Context) {
    defer close(op.done)
    defer op.cancel()

    // ❌ 缺少 panic 恢复！如果 execFunc panic：
    // 1. resultCh 没有结果，Get() 永久阻塞
    // 2. 状态停留在 StatusRunning
    // 3. 资源泄漏

    value, err := op.execFunc(ctx)
    // ...
}
```

**修复建议**:
```go
func (op *AsyncOp[T]) execute(ctx context.Context) {
    defer close(op.done)
    defer op.cancel()

    // ✅ 添加 panic 恢复
    defer func() {
        if r := recover(); r != nil {
            op.statusMu.Lock()
            op.status = StatusFailed
            op.err = fmt.Errorf("panic in async operation: %v", r)
            op.statusMu.Unlock()

            // 发送结果到 channel，防止 Get() 阻塞
            select {
            case op.resultCh <- Result[T]{Err: op.err}:
            default:
            }

            slog.Error("[async] operation panic recovered", "panic", r)
        }
    }()

    // ... 原有逻辑 ...
}
```

**优先级**: P1（强烈建议在合并前修复）

#### P1-03: TypedResult 类型断言对 nil 值处理不当

**影响**: 任务返回 nil 时类型断言失败

**问题示例**:
```go
result := SubmitWithResultTyped[*MyStruct](provider, ctx, func(ctx context.Context) (*MyStruct, error) {
    return nil, nil // nil 无法进行类型断言
})

val, err := result.Get(ctx)
// ❌ 类型断言失败：expected *main.MyStruct, got <nil>
```

**修复建议**:
```go
func assertType[T any](anyVal any) (T, error) {
    var zero T

    // ✅ 特殊处理 nil 值
    if anyVal == nil {
        typ := reflect.TypeOf(zero)
        if typ == nil || typ.Kind() == reflect.Ptr || typ.Kind() == reflect.Interface {
            return zero, nil // 允许返回 nil
        }
        return zero, errors.Wrapf(errors.ErrAsyncExecFailed,
            "type assertion failed: expected %T, got <nil>", zero)
    }

    val, ok := anyVal.(T)
    if !ok {
        return zero, errors.Wrapf(errors.ErrAsyncExecFailed,
            "type assertion failed: expected %T, got %T", zero, anyVal)
    }
    return val, nil
}
```

**优先级**: P1（建议修复）
