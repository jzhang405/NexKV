#### 3. 多级分裂支持（2-3 小时）

**文件**：`split.go`（修改）

**修改内容**：
- 实现完整的 `insertSplitIntoParent`
- 支持任意层级的分裂传播

**步骤**：
1. 递归向上传播分裂
2. 如果父节点也满，继续分裂父节点
3. 直到找到不满的父节点或到达根节点

**实现方案**：
```go
func (t *BfTree) insertSplitIntoParent(parentPageID, leftPageID, rightPageID uint64, splitKey []byte) error {
    // 获取父节点
    parentNode, err := t.pageStore.getInner(parentPageID)
    if err != nil {
        return err
    }

    // 尝试插入分隔键和子节点
    if !parentNode.IsFull() {
        // 直接插入
        return parentNode.InsertChild(...)
    }

    // 父节点也满了，需要分裂
    left, right, newSplitKey, oldParentID, err := t.splitInnerNode(parentPageID)
    if err != nil {
        return err
    }

    // 递归向上
    grandParentID := t.findParent(parentPageID)
    if grandParentID == 0 {
        // 到达根节点，创建新根
        return t.createNewRoot(left, right, newSplitKey)
    }

    return t.insertSplitIntoParent(grandParentID, left, right, newSplitKey)
}
```
