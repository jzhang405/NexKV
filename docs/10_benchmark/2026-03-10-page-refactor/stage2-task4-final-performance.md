## 🔬 优化建议

### 1. Split 进一步优化（可选）

**当前**: 9.4 µs
**优化**: 减少内存分配

```go
// 当前：分配新的 ChildIDs 切片
rightNode.ChildIDs = append(rightNode.ChildIDs, n.ChildIDs[mid+1:]...)

// 优化：预分配容量（可选）
rightNode.ChildIDs = make([]model.PageID, 0, len(n.ChildIDs[mid+1:]))
rightNode.ChildIDs = append(rightNode.ChildIDs, n.ChildIDs[mid+1:]...)
```

**预期收益**: 减少 **~10-20%** 分配时间

### 2. InsertChild 批量优化（可选）

**场景**: 插入多个子节点
**优化**: 预分配切片容量

```go
// 当前：逐个扩展
for len(n.Children) <= idx+1 {
    n.Children = append(n.Children, nil)
}

// 优化：一次扩展到所需容量
if cap(n.Children) < needed {
    n.Children = append(n.Children, make([]*Node, needed-len(n.Children))...)
}
```

**预期收益**: 减少 **~15-25%** 分配时间
