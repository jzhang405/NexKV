## 分析

- 1T/2T: 基本持平，offheap DebugPrintf 对低并发影响小
- 4T: 提升 56.5%，说明 offheap 调试代码在高并发下引入了显著开销
- 8T: 提升 162.6%，offheap DebugPrintf 的 if 分支和字符串拼接在 8 线程下造成严重瓶颈
- 2T 下降可能是运行时波动（与 Phase 0 数据对比），需多次运行确认

## 结论

offheap 包的 DebugPrintf 调用（主要是 page_lifecycle_tracker 中的追踪代码）在高并发场景下
引入了显著性能开销。清空后 8T 性能提升 2.6x。
